Figure templates

A handful of templates covers nearly every figure the site needs. Copy the HTML under each figure and swap the text — no coordinates to compute; it scales to the screen and matches the palette on its own.

00

Color conventions

Every figure on the site shares four colors, one meaning each. Never change the meaning between lessons.

bluedata, item under consideration
amberpointer, highlight, answer
redwrong, rejected, not yet met
greencorrect, result, satisfied
  • One figure per section is enough. Two figures in one section usually means it should be split.
  • A figure must replace a paragraph, not merely illustrate it.
  • Keep text in figures to a minimum — long explanations go in a figcaption or bullet points.

eq — display formula

A standalone formula, each term labeled right below it. The browser handles alignment — no column counting as with <pre>.

E[(y − f̂(x))2] = ( E[f̂(x)] − f(x) )2bias² + E[( f̂(x) − E[f̂(x)] )2]variance + σ2noise
f̂(x)
model prediction, varies with the training set
f(x)
ground truth, fixed and unknowable
<div class="eq">
  <div class="line">
    <span class="t"><span>left side</span></span>
    <span class="op">=</span>
    <span class="t b"><span>term</span><em>label</em></span>   <!-- b·p·g·r = 4 semantic colors -->
  </div>
  <dl><dt>symbol</dt><dd>meaning</dd></dl>    <!-- optional -->
  <p class="read">one sentence reading the formula</p>   <!-- optional -->
</div>
  • Only for standalone formulas. Derivations with prose comments, number tables, and multi-line reasoning stay in <pre><code> — don't force them in here.
  • Use Unicode symbols directly: Σ ∏ ∂ ∇ σ λ θ μ ≈ ∝ ≤ ⁻ ⱼ ᵢ. For arbitrary exponents and subscripts use <sup> / <sub>; don't hunt for rare Unicode characters.
  • For multiple lines, use one .line each; later lines usually start with <span class="op">=</span> to keep the steps aligned.
  • Label colors use the four semantic colors from section 00 — r for irreducible terms, g for results. For no color, leave the class out.
10

When SVG is actually needed

Only when the figure has curves, diagonals, or real coordinate axes. Otherwise use the HTML templates above.

  • Needs SVG: bar charts with real values, learning curves, diagonal arrows between blocks, function shapes.
  • No SVG needed: boxes joined by straight arrows, tables, cell rows, axes with discrete stops — HTML templates scale on their own and are much faster to edit.
  • Write SVG following the rotated array example: viewBox="0 0 560 200", bars 60 wide, 12 apart, baseline y=158 — keep this frame and every bar chart on the site looks like one set.

Text classes for SVG

Don't write font-family or fill directly on <text> — with these five classes every figure shares one type set, and changing the palette in :root updates the figures too.

ClassUsed for
.sv-hheading for a region of the figure — mono, uppercase, letter-spaced
.sv-tmain label of a block
.sv-nvariable names, values, numbers — mono at a readable size
.sv-lsmall mono notes: addresses, formulas
.sv-dfaint prose note, placed under the main label

If a figure is so detailed that text turns to mush at 490px, wrap it in <figure class="scrollx"> so it scrolls horizontally in its own frame instead of shrinking. Full example in the memory map.
