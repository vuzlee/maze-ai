Mamba

It fixes exactly the weak spot of SSM: knowing what is worth remembering.

Skeleton — outline settled, content not yet written.

01

Problem it solves

An SSM has fixed matrices, so it cannot tell important tokens from filler.

02

Core idea

Make B, C and the discretization step depend on the input itself — one figure.

03

Mechanism

Selective scan · a parallel scan algorithm optimized for GPU memory.

04

Objective function

Still next-token prediction; the difference is in the mixing layer.

05

Trade-offs

Linear-time inference with no KV cache; in exchange it is weaker at precise in-context retrieval.
