Networking overview

Two machines talking over an unreliable wire. Opening a URL takes four steps — DNS, TCP, TLS, HTTP — and each has its lesson.

01

Opening a URL

Find the address, connect, secure the line, then ask for the page.

  • DNS turns a name into an IP address.
  • TCP opens a reliable connection; TLS encrypts it; HTTP carries the request.
02

Round trips

Each step waits for a reply — distance costs time.

  • RTT (round-trip time): Paris ↔ New York is about 80 ms.
  • Keep-alive reuses a connection; a CDN moves the server closer.
03

Learning order

Layers first, then each step in the order a request uses it.
