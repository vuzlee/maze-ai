OSI model

A shared map of who does what in a network.

  • seven layers on paper, four you really meet
  • each layer has one job and its own address
  • going down, each layer wraps the packet in a header
01

Mental model

Seven OSI layers; real software uses the four TCP/IP layers.

  • Layers 6 and 5 live inside applications; layer 1 is cables and radio.
02

The four layers

Each layer answers one question.

2.1Application (L7)

What do the programs say?

2.2Transport (L4)

Which program gets it — by port.

  • An L4 load balancer routes by IP and port; an L7 one reads the HTTP request — see Load balancing.

2.3Network (L3)

Which machine — by IP address, hop by hop.

2.4Data link (L2)

The next hop on the local network — by MAC address.

03

Encapsulation

Layers wrap on the way down and unwrap on the way up.

3.1Sending

Each layer adds its header in front.

3.2Receiving

Each layer removes its own header and passes the rest up.
