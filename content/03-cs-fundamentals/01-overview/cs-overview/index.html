CS fundamentals

The layer under every program you write: the operating system shares one machine, and networking connects two. Every web request crosses both.

01

What CS fundamentals is

The operating system shares one machine between many programs; networking lets two machines talk. This shelf is these ten pictures.

  • Both halves hide hard problems behind a simple promise — “you have the whole machine” and “bytes arrive in order” — and knowing how the promise is kept explains why it sometimes breaks.
  • Language-independent: Python, Java and C all ask the same OS for threads, memory and sockets. Thread scheduling is taught once, in Process, thread & GIL.
02

What happens when you type a URL

One request goes down every layer on your machine, crosses the wire, and climbs the same layers on the server.

  • Each layer only talks to the one above and below — that is why HTTP does not care whether the wire is Wi-Fi or fibre. The full model is in OSI model.
  • The lower layers run inside the OS kernel, which is where the two halves of this shelf meet. Many machines acting as one opens the Distributed systems shelf.
03

Learning order

Inside one machine first, then out onto the network.
