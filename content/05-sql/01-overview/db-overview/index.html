Database · relational basics

Database overview

A database stores data so many users can read and change it safely.

  • relational databases store tables linked by keys
  • SQL is the language to query them
  • learn design first, then queries, then performance
01

Mental model

Design the tables first, then query them.

02

Types of database

Same data, different shapes. Relational is the default.

2.1Relational

Tables with fixed columns, linked by keys.

PostgreSQL, MySQL — the default: rules, joins, transactions.

2.2Key-value

Look up one value by one key, very fast.

Redis, DynamoDB — cache, sessions, shopping carts.

2.3Document

Each record is a JSON document of any shape.

MongoDB — records whose fields vary.

2.4Graph

Data is nodes and edges.

Neo4j — social networks, recommendations.

03

SQL commands

SQL has three families of commands.

3.1DDL

Define the shape of tables.

CREATE · ALTER · DROP · TRUNCATE

3.2INSERT

Add new rows.

INSERT INTO customers (name, city) VALUES ('Carol', 'Oslo')

3.3UPDATE

Change existing rows.

UPDATE customers SET city = 'Berlin' WHERE id = 2

  • Without WHERE every row changes.

3.4DELETE

Remove rows.

DELETE FROM customers WHERE id = 1

  • Without WHERE every row is deleted.

3.5DCL

Control who can do what.

GRANT SELECT ON orders TO analyst · REVOKE takes it back.
