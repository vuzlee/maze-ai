Database · SQL basics

GROUP BY & aggregate

Summarize many rows into one row per group.

  • GROUP BY makes one row per group
  • aggregates (COUNT, SUM, AVG…) summarize each group
  • WHERE filters rows, HAVING filters groups
01

Mental model

Rows with the same key collapse into one.

Syntax: SELECT name, SUM(amount) FROM orders GROUP BY name.

  • Every column in SELECT must be in GROUP BY or inside an aggregate.
02

Aggregate functions

Turn a group of values into one value; all except COUNT(*) skip NULL.

2.1COUNT

Count rows or non-NULL values.

2.2SUM

Add up the values.

2.3AVG

Average of non-NULL values.

2.4MIN and MAX

Smallest and largest value.

03

Filtering and grouping

When to filter, and grouping by more than one column.

3.1WHERE vs HAVING

WHERE removes rows before grouping; HAVING removes groups after.

Order: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.

3.2Grouping by several columns

One group per unique combination.

GROUP BY city, year
