Subquery & CTE

Use the result of one query inside another.

  • a subquery sits in parentheses
  • a CTE names it with WITH
  • correlated subqueries run once per outer row
01

Mental model

The inner query runs first; its result becomes a value for the outer query.

02

Where a subquery goes

The place decides the shape it must return.

2.1In WHERE

Returns a value or a list to compare against.

2.2In FROM

Returns a table you query again.

2.3In SELECT

Returns one value per row.

2.4EXISTS

True when the inner query finds any row.

WHERE EXISTS (SELECT 1 FROM orders o WHERE o.cust = c.id)

  • This is correlated: it runs once per outer row.
03

CTE

Name a step with WITH, then use it like a table.

  • Chain them: WITH a AS (…), b AS (…).
  • WITH RECURSIVE walks a tree such as an org chart.
04

Set operations

Combine the results of two queries with the same columns.

4.1UNION

Rows in either, duplicates removed.

4.2UNION ALL

Rows in either, duplicates kept — faster.

4.3INTERSECT

Rows in both.

4.4EXCEPT

Rows in A but not in B.
