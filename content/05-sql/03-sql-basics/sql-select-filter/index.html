Database · SQL basics

SELECT, WHERE & ORDER BY

Read, filter and sort rows from one table.

  • SQL runs FROM → WHERE → SELECT → ORDER BY
  • WHERE removes rows, SELECT picks columns
  • test for NULL with IS NULL
01

Mental model

SQL does not run in the order you write it — SELECT runs late.

  • WHERE cannot use a column alias from SELECT; ORDER BY can.
02

WHERE

WHERE checks each row and keeps rows where the condition is true.

2.1Comparison

= != < > <= >=

WHERE amount > 100

2.2AND, OR, NOT

Combine conditions; AND binds first.

WHERE a > 1 AND (b = 2 OR c = 3) — use parentheses.

2.3BETWEEN

A range, both ends included.

WHERE amount BETWEEN 100 AND 300

2.4IN

Matches any value in a list.

WHERE status IN ('paid', 'sent')

2.5LIKE

Pattern match: % any text, _ one character.

WHERE name LIKE 'A%'

2.6IS NULL

The only way to test for NULL.

WHERE email IS NULL — never = NULL.

03

Shaping the result

Pick columns, remove duplicates, sort, cut.

3.1SELECT

Pick and name columns.

SELECT name, amount * 2 AS doubled

3.2DISTINCT

Drop duplicate rows from the result.

SELECT DISTINCT city FROM customers

3.3ORDER BY

Sort rows; ASC is the default.

ORDER BY amount DESC, name

3.4LIMIT

Keep the first N rows.

LIMIT 2 · OFFSET 2 skips rows for paging.

04

Expressions

Compute new values inside SELECT.

4.1CASE

Turn values into labels with if/else rules.

CASE WHEN amount < 100 THEN 'small' WHEN amount < 500 THEN 'medium' ELSE 'large' END

4.2NULL handling

Any math with NULL gives NULL — replace it first.

  • COALESCE(a, b, …) returns the first non-NULL value.
  • IS NULL to test; never = NULL.

4.3Functions

Built-in functions transform one value.

  • Text: LOWER, LENGTH, SUBSTRING, CONCAT.
  • Number: ABS, CEIL, FLOOR.
  • Date: CURRENT_DATE, DATE_TRUNC.
