Window functions

Compute across rows while keeping every row.

  • GROUP BY collapses rows; a window keeps them
  • OVER (PARTITION BY … ORDER BY …) defines the window
  • used for ranking, running totals, previous/next row
01

Mental model

Same calculation as GROUP BY, but every row stays.

02

The OVER clause

Two optional parts define the window.

2.1PARTITION BY

Split rows into groups; the function restarts in each.

SUM(amount) OVER (PARTITION BY name)

2.2ORDER BY

Order rows inside each group — turns totals into running totals.

SUM(amount) OVER (PARTITION BY name ORDER BY day)

03

Window functions

Ties and neighbour rows are where they differ.

3.1ROW_NUMBER

Unique numbers, even for ties.

3.2RANK

Ties share a rank, then a gap.

3.3DENSE_RANK

Ties share a rank, no gap.

3.4LAG and LEAD

Value from the previous / next row.
