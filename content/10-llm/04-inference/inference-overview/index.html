Inference overview

Generation is bound by memory bandwidth, not FLOPs — understand that sentence and you understand the whole group.

Skeleton lesson — outline settled, content not yet written.

01

Map

The life of one request: prompt → prefill → decode loop (Decoding strategies pick each token) → output, with Quantization shrinking the weights and Inference optimization (KV cache, batching, speculative decoding) speeding the loop; each part links.

02

Which one

Pick by the bottleneck: output quality / variety → decoding strategy; model does not fit in memory → quantization; too slow or too costly per token → inference optimization.

03

Learning order

Decoding strategies → Quantization → Inference optimization.
