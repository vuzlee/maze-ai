SQL basics overview

Câu SQL không chạy theo thứ tự bạn viết. Nắm thứ tự thật là gỡ được phần lớn lỗi của người mới.

01

Thứ tự thực thi thật

Đây là điểm hay bị hỏi phỏng vấn nhất của cả nhóm: SQL viết theo một thứ tự nhưng chạy theo thứ tự khác hẳn.

Trong khi đó bạn gõ theo thứ tự SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY.

Hai thứ tự lệch nhau ngay ở vị trí đầu: SELECT gõ trước nhưng chạy gần cuối.

Vì sao lệch nhau lại quan trọng

Vì SELECT chạy sau WHERE, alias đặt trong SELECT chưa tồn tại khi WHERE chạy — đây là lý do WHERE price_vnd > 100 báo lỗi "column không tồn tại" trong khi ORDER BY price_vnd lại chạy được bình thường. Bài SELECT, WHERE & ORDER BY đào sâu đúng chi tiết này.
  • SQL mô tả kết quả muốn thấy, không nói làm bằng cách nào — database toàn quyền chọn quét bảng hay dùng index.
  • Cái giá: đọc một câu SQL phức tạp phải tưởng tượng ngược theo sáu bước trên, không phải theo thứ tự dòng chữ.
