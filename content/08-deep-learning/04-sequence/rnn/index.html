RNN

The first architecture with memory — and also the first to forget.

Skeleton — outline settled, content not yet written.

01

Problem it solves

A plain network cannot take sequences of varying length and remembers nothing between steps.

02

Core idea

Reuse the same weights at every time step, carrying a hidden state along — one figure.

03

Mechanism

The recurrent step · backpropagation through time.

04

Objective function

Still cross-entropy at each step; the difficulty lies in the gradient across many steps.

05

Trade-offs

Handles sequences of any length; in exchange it cannot be parallelized and forgets distant information.

06

Used in which models

The predecessor of LSTM/GRU, and the reference point for understanding why the Transformer won.

Common mistakes
