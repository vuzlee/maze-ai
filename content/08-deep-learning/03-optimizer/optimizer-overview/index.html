Deep learning · Optimizer

Optimizer overview

Backprop gives the gradient; an optimizer turns it into a step. Five optimizers, each fixing one problem of the one before — from plain SGD to AdamW, the default for LLMs.

01

Family tree

Two ideas grow out of SGD — remember past steps and a step size per weight — and Adam joins them.

  • Every optimizer still computes the same gradient from Backpropagation; they differ only in how that gradient becomes a step.
  • Variants you will meet by name — Nesterov, AMSGrad, Adafactor, Lion — are small changes to one box on this tree.
02

Same valley, four paths

On a long thin valley the difference is visible at a glance: SGD zig-zags, adaptive steps go straight down the floor.

  • The valley is the toy every lesson in this group uses: one weight's direction is 8.5× steeper than the other's — the shape that makes optimizers differ.
  • Fastest here is not best everywhere: tuned SGD + momentum often generalises a little better on image models.
03

Which one to use

Start with AdamW + warmup + cosine decay; reach for SGD + momentum only when a CNN recipe says so.

  • Adam-style optimizers keep two numbers per weight, so they need about 3× the weight memory — the reason 8-bit optimizers exist for large models.
  • The learning rate matters more than the choice of optimizer; its schedule is in SGD & mini-batch.
04

Learning order
