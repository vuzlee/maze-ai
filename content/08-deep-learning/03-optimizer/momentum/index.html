Deep learning · Optimizer

Momentum

Carry part of the last step forward: zig-zags across a narrow valley cancel out, steps along it add up; Nesterov looks ahead.

01

Velocity

Step along a velocity that adds up past gradients: zig-zag parts cancel, the steady direction grows.

  • β = 0.9 is the usual default; with β = 0.5 here the velocity remembers about two steps.
  • SGD + momentum (often Nesterov, which reads the gradient one step ahead) is still the standard for training CNNs on images.
02

Nesterov momentum

Nesterov reads the gradient at the look-ahead point the velocity is heading for, so it brakes before it overshoots.

  • Same two numbers to tune as momentum (η, β); the only change is where the gradient is read.
  • It helps most when β is large: here at β = 0.7 plain momentum overshoots the floor, Nesterov does not.
  • In PyTorch: torch.optim.SGD(params, lr, momentum=0.9, nesterov=True).
