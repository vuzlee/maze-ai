Dropout & regularization

A network big enough to learn the pattern is big enough to memorise the noise, so training adds a few deliberate handicaps.

01

Mental model

Training loss keeps falling while validation loss turns back up: the network has started memorising.

  • The general idea — overfitting, bias–variance, why fewer effective parameters help — is in Overfitting & regularization; this lesson is the deep-learning toolbox.
  • Every tool below makes memorising harder: noise in the network (dropout), small weights (weight decay), less time (early stopping), more data (augmentation).
02

Dropout

Switch off random neurons only while training; at inference use the whole network.

h̃what the next layer sees = m ⊙ h1 − pm ~ Bernoulli(1 − p) per neuron

2.1At training

Each step draws a new mask; survivors are scaled by 1/(1 − p) so the expected sum stays the same.

  • No neuron can rely on one particular partner, so features must work on their own — like training many thinned networks that share weights.
  • This is inverted dropout: the scaling happens at training, so inference needs no change. Typical p: 0.1–0.5.

2.2At inference

No mask, no scaling: the full network gives one fixed answer.

  • The full network approximates the average of all the thinned ones.
  • Classic bug: forgetting model.eval() leaves dropout on, and predictions change on every call.
03

Weight decay

Add a cost for large weights, so every step shrinks each weight a little toward 0.

Ltotalwhat is minimised = Ldatacross-entropy + λ2 ‖w‖2L2 penalty
wupdate ← w − η ∇Ldatausual gradient step − η λ wthe decay
  • Small weights mean a smoother function: a tanh with small inputs is almost linear, so the border cannot bend around single points.
  • With plain SGD the two lines are the same thing. With Adam they are not — the penalty gets rescaled per weight — which is why AdamW applies the decay directly to the weights.
04

Early stopping

Watch validation loss, keep the best checkpoint, stop when it has not improved for a while.

  • Patience = how long to wait without improvement; validation loss is noisy, so never stop at the first rise.
  • Almost free and works with every other tool; the validation set must not be used for anything else.
05

Data augmentation

Make new training rows by transforming old ones in ways that do not change the label.

  • Images: flip, shift, crop, rotate, colour jitter; text: synonym swap, back-translation; audio: noise, time shift.
  • Only transforms the label survives: a flipped cat is a cat, a flipped "6" may be a "9".
  • Applied fresh every epoch, so the network rarely sees the exact same input twice.
06

Label smoothing

Replace the hard 1/0 target by a little less than 1, so the network stops chasing infinite confidence.

  • Common in large classifiers and Transformers (ε ≈ 0.1); also tends to improve calibration.
  • Batch norm also regularises a little: each sample is normalised with statistics of a random mini-batch, which adds noise — see Normalization.
