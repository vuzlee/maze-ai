Activation functions

An activation function bends each layer's weighted sum, and without that bend a deep network collapses into one linear map.

01

Mental model

Two linear layers multiply into one matrix; a nonlinear φ between them stops the merge.

W2(W1x)two layers, no φ = (W2W1)xregroup = Wxone layer
hlayer output = φapplied to every number ( Wx + bweighted sum z )
  • Any number of stacked linear layers is still one line, so a network without φ cannot even solve XOR — see Neural network overview.
  • φ works element by element on z; what it does to the slope φ′ matters as much as its shape, because backprop multiplies by φ′ at every layer.
02

The common functions

Each one is a curve and a slope; the same three inputs z = −2, 0.5, 2 go through all of them.

2.1Sigmoid

Squashes any z into (0, 1); flat at both ends.

σ(z)activation = 11 + e−zsquashes into (0, 1)
σ′(z)slope = σ(z) (1 − σ(z))at most 0.25, at z = 0
  • Slope is at most 0.25 and nearly 0 for |z| > 4: the saturation behind section 03.
  • Outputs are all positive, so the next layer's gradients all share one sign and zig-zag. Today it lives in output layers and gates (LSTM), not hidden layers.

2.2Tanh

A sigmoid stretched to (−1, 1) and centred on zero.

tanh(z)activation = 2σ(2z) − 1a sigmoid stretched to (−1, 1)
tanh′(z)slope = 1 − tanh2(z)at most 1, at z = 0
  • Zero-centred outputs and a slope up to 1 train faster than sigmoid, but it still saturates for large |z|.
  • The default inside RNN and LSTM cells.

2.3ReLU

Keep positive z, cut negatives to 0.

ReLU(z)activation = max(0, z)negatives cut to 0
ReLU′(z)slope = 1 if z > 0, else 0all or nothing
  • Slope exactly 1 for every positive z: no saturation on that side, and it costs one comparison. The default for hidden layers since AlexNet (2012).
  • Slope 0 for every negative z — a neuron stuck there stops learning (section 04). Pair it with He initialization.

2.4Leaky ReLU & ELU

ReLU with a small slope on the negative side, so the gradient never dies.

LeakyReLU(z)activation = max(αz, z)α small, e.g. 0.01
LeakyReLU′(z)slope = 1 if z > 0, else αnever exactly 0
  • Drawn with α = 0.1 to be visible; PyTorch's default is 0.01. PReLU learns α.
  • ELU bends smoothly to −1 instead of a straight line: ELU(−2) = −0.865, slope ez for z < 0.

2.5GELU

A smooth ReLU: z weighted by the chance a normal draw is below it.

GELU(z)activation = z · Φ(z)Φ = normal CDF: keep z with probability Φ(z)
GELU′(z)slope = Φ(z) + z φN(z)φN = normal density
  • The activation inside the Transformer feed-forward block: BERT, GPT-2/3, ViT all use GELU.
  • SiLU / Swish is the same idea with σ in place of Φ: z · σ(z), SiLU(−2) = −0.238; SwiGLU in LLaMA builds on it.
03

Saturation & vanishing gradients

The gradient reaching layer 1 is a product of slopes; slopes below 1 shrink it layer by layer.

∂L∂a0gradient at the first layer = φ′(z1) · φ′(z2) ⋯ φ′(z6)one slope per layer, here ≤ 0.25 each · ∂L∂a6gradient at the output
  • With weights the factor is w · φ′; the full story, and its opposite (exploding), is in Backpropagation.
  • ReLU's slope of 1 lets the gradient pass unchanged, which is why deep nets switched to it.
04

Dying ReLU

A neuron whose z is negative for every row outputs 0, gets gradient 0, and never recovers.

  • Usually caused by a too-large learning rate or a large negative bias knocking the neuron past every row; check the share of zeros per layer.
  • Fixes: a smaller learning rate, Leaky ReLU / GELU, and He initialization, which is sized for ReLU.
05

Output layer

Hidden layers use ReLU or GELU; the last layer uses whatever turns logits into the answer's shape.

5.1Binary: sigmoid

One logit per row becomes one probability of the positive class.

pP(class 1) = σ(z)z = the raw output, the logit
  • Also for multi-label (an image can be cat and dog): one sigmoid per label, each on its own.
  • Train on the logit with BCEWithLogitsLoss; it applies σ inside, more stably.

5.2Multiclass: softmax

K logits become K probabilities that add up to 1.

pkP(class k) = ezkΣj ezjexp, then divide by the sum
  • Exactly one class is right. CrossEntropyLoss takes the raw logits — adding a softmax before it applies softmax twice.
  • Regression keeps the output linear (no φ); a positive target can use softplus or exp.
