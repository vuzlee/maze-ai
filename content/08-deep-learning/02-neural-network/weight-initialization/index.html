Deep learning · Neural network

Weight initialization

Start every weight random, different and the right size, so neurons learn different things and the signal neither fades nor blows up across layers.

01

Symmetry

Neurons that start equal compute the same value, get the same gradient, and stay equal forever.

  • Zero is the worst constant: on XOR every gradient is exactly 0 and nothing moves at all.
  • Random weights break the tie; biases can start at 0, the weights already make each neuron different.
02

Scale

Each layer multiplies the spread of the signal by a factor; ten layers raise it to the tenth power.

2.1Too small

A factor below 1 shrinks the spread to a spike at zero.

  • Every later layer sees almost the same input, and gradients shrink the same way: vanishing gradients.

2.2Too large

A factor above 1 blows the spread up until values overflow.

  • Sigmoid and tanh saturate, ReLU passes huge values on; gradients explode and the loss turns NaN: exploding gradients.
03

The 1/n rule

A neuron sums n terms, so the variance grows n times — shrink each weight's variance by n to cancel it.

Var(z)spread after the layer = ninputs summed · Var(w)weight spread · Var(x)spread before
Var(z) = Var(x)keep the spread ⇒ Var(w) = 1nstd = √(1/n)
  • Assumes weights and inputs are independent with mean 0 — true at the start, which is all init has to get right.
  • After training starts the weights move; keeping the spread steady from then on is the job of normalization.
04

Xavier and He

The same rule, corrected for what the activation does to the spread.

4.1Xavier / Glorot

For tanh and sigmoid: average the forward need (1/nin) and the backward need (1/nout).

Var(w)Xavier = 2nin + nout= 1/n when the layer is square
  • tanh is roughly linear near 0, so the plain 1/n rule holds; drawn too wide, values land where tanh is flat and its gradient is ~0.
  • Keras Dense uses Xavier-uniform by default.

4.2He / Kaiming

For ReLU: it zeroes half the values and halves the variance, so double the weight variance.

Var(w)He = 2ninthe 2 undoes ReLU's half
  • Use it for ReLU and its relatives (Leaky ReLU, GELU) — see activation functions.
  • PyTorch nn.Linear defaults to a Kaiming-uniform variant (a=√5): U(−1/√nin, 1/√nin), a bit smaller than He; call nn.init.kaiming_normal_ to get He exactly.
