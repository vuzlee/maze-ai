Deep learning · Neural network

Perceptron & MLP

One neuron is a weighted sum, a bias and a threshold — a single straight line; XOR shows why you need a hidden layer of them.

01

Mental model

A neuron multiplies each input by a weight, adds a bias, and fires if the sum is above zero.

ŷ0 or 1 = step1 if z > 0 (w1x1 + w2x2 + b)z: weighted sum + bias
  • This is Rosenblatt's perceptron (1958); the step is the first activation function.
  • z = 0 is a straight line on the input plane: one side fires, the other does not.
02

Perceptron learning rule

On every wrong row, move each weight by η · error · input; stop after a pass with no mistake.

w ← wold weight + ηlearning rate (y − ŷ)error: +1, 0 or −1 xinput on that edge
  • Right rows change nothing; a wrong row pushes the line toward its own side.
  • If some line separates the classes, the rule is guaranteed to find one in a finite number of mistakes.
03

The XOR problem

XOR puts each class on opposite corners: no straight line separates them, so the rule never stops.

  • Minsky and Papert (1969) made this limit famous; funding for neural networks dried up — the first AI winter.
  • The fix is not a better rule but more neurons: lines combined in a second layer.
04

Hidden layer

A multilayer perceptron (MLP) feeds the outputs of several neurons into the next neuron.

4.1Hidden neurons

Each hidden neuron is one perceptron: it draws its own line and outputs how far a point is on its firing side.

  • The step is replaced by a smooth sigmoid σ, so outputs are between 0 and 1 and the weights can be trained by backpropagation.
  • These weights came from 3,000 gradient-descent steps on the four rows, seed 1 — nobody picked them by hand.

4.2Hidden space

The hidden outputs are new coordinates; there XOR becomes separable and the output neuron cuts it with one line.

  • Folded back onto the input plane, that one line becomes the band between the two hidden lines.
  • This is what "learning features" means: the hidden layer moves the data until the last layer's job is easy.
05

Forward pass

A prediction is one sweep left to right: every layer is a matrix product, a bias, then σ.

hhidden outputs = σapplied to each entry (W1x + b1)W1: one row of weights per hidden neuron , ŷ = σ(w2 · h + b2)the output neuron
  • A batch of inputs is a matrix X: the same pass becomes σ(XWT + b), one GPU call per layer.
  • Without σ two layers collapse into one matrix — still one straight line.
06

Layers and parameters

Each layer owns a weight matrix and a bias vector: inputs × outputs + outputs numbers to learn.

  • Depth = number of weight layers; width = neurons per layer. Most parameters sit next to the widest layers.
  • Universal approximation: one hidden layer, wide enough, can approximate any continuous function — but it says nothing about how wide, or whether training finds it.
