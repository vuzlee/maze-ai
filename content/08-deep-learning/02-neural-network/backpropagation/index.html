Deep learning · Neural network

Backpropagation

Backpropagation runs the network forward once, then sends one error backwards, multiplying by each step's local derivative, so every weight gets its gradient in a single sweep.

01

Mental model

Values flow forward through a graph of small operations; gradients flow backward, each node multiplying by its own local derivative.

  • Each node only knows its local derivative (a × node sends back the other input, a + node passes the gradient through).
  • The forward pass must store its values: the backward pass needs q and z again.
  • One backward sweep costs about as much as one forward pass, whatever the number of weights — that is why it beats perturbing weights one by one.
02

Chain rule

The gradient from the loss to any value is a product along each path, summed over paths.

2.1Along a path

Composed functions: multiply the local derivatives link by link.

dydxwhat we want = dyduouter link · dudxinner link

2.2Where paths merge

A value used twice gets gradients from both uses: add them.

  • This is why frameworks accumulate into .grad — and why you call optimizer.zero_grad() before each step.
03

A 2-2-1 network by hand

Two inputs, two sigmoid hidden neurons, one sigmoid output, log loss, one sample with y = 1.

3.1Forward pass

Each neuron sums its weighted inputs and squashes them; the output enters the loss.

z = Σ wx + bweighted sum , a = σ(z)activation , L = −log ŷlog loss for y = 1

3.2Backward pass

An error δ starts at the output and rides back; each weight's gradient is δ times the input on its edge.

δout = ŷ − ysigmoid + log loss , δh = v · δout · σ′(z)one layer back , ∂L∂w = δ · inputgradient of an edge
  • σ′(z) = a(1 − a), so the stored activations are all the backward pass needs.
  • In matrix form one layer is δl = (W⊤δl+1) ⊙ σ′(z) and ∂L/∂W = δ a⊤: every gradient has the shape of its weight.

3.3Update

Step every weight against its gradient; the next forward pass has a lower loss.

  • Here one step takes the loss from 0.533 to 0.387. How the step is sized — momentum, Adam — belongs to Optimizer.
04

Softmax + cross-entropy

For many classes the output error is just as simple: probabilities minus the one-hot label.

pk = ezkΣj ezjsoftmax , L = −log pycross-entropy ⇒ ∂L∂z = p − ythe gradient on the logits
  • The messy derivative of softmax cancels against the log: no division, no exponent in the gradient.
  • Use the fused loss (nn.CrossEntropyLoss on raw logits); a separate softmax then log is numerically unstable.
05

Vanishing & exploding gradients

The gradient reaching layer 1 is a product of one factor per layer: slightly below 1 shrinks it, slightly above 1 blows it up.

5.1Vanishing — sigmoid

σ′ is at most 0.25, so each layer cuts the gradient by 4× or more.

  • The first layers barely move: training looks stuck although the last layers learn.

5.2Stable — ReLU + He init

ReLU's slope is 1 where active; with weights of variance 2/n each layer keeps the size.

  • Why 2/n works is in Weight initialization; Normalization and residual connections keep it stable during training.

5.3Exploding — weights too large

Same ReLU net with weights of variance 6/n: each layer multiplies the gradient by about 1.7.

  • Symptom: loss jumps to nan. Quick fix: gradient clipping (clip_grad_norm_), common in RNNs and Transformers.
06

Gradient checking

Nudge one weight both ways and measure the slope: it must match backprop's number.

∂L∂wfrom backprop ≈ L(w + h) − L(w − h)2hcentral difference
  • Relative error below about 1e−6 in float64 means the backward code is right; a big h measures the curve, not the slope.
  • Two forward passes per weight: use it on a tiny net to test code, never to train.
  • When a model will not learn, check in order: overfit one batch to near-zero loss → loss at step 0 ≈ log(classes) → no nan → gradient size per layer → learning rate.
