Neural network overview

A deep network is neurons in layers plus a handful of fixes, each patching the failure that appears as the network gets deeper. This page is the map; every piece has its own lesson.

01

The network

Inputs go forward through weighted, bent layers to a loss; gradients come back and the optimizer nudges every weight.

  • Forward: each layer computes h = σ(Wx + b). Backward: one pass gives the gradient of every weight.
  • The optimizer has its own group: Optimizer overview.

What breaks without each piece
