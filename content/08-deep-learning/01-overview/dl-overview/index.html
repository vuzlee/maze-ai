Deep learning overview

Deep learning is machine learning with many layers of neurons that learn their own features: the classic pictures of the field — neuron, layers, backprop, CNN, RNN, LSTM, generative models — and the history from the perceptron to attention.

01

What deep learning is

Deep learning is machine learning with many layers of neurons, trained end to end by backpropagation.

  • Continues Machine learning: the same loop of predict, measure the loss, adjust — the model is now layers of neurons.
  • Attention is not here: it opens the Transformer shelf.
02

Learned features

Classic ML needs a person to design features; a deep network learns them layer by layer.

  • “Deep” means many stacked layers: early layers find simple patterns, later layers combine them.
  • The price: lots of data, lots of compute, and a model that is hard to explain.
03

History

Every milestone is the fix for the wall the previous one hit.

  • The 2012 jump needed three things at once: ImageNet-sized data, GPUs, and ReLU-style training tricks.
  • This shelf ends where attention appears; the same timeline continues in the Architecture overview.
04

Learning order

Learn to train one plain network first; CNN and RNN are the same training with a different layer.

  • Every stop is a link. The last one opens the Transformer shelf.
