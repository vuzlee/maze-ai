Core concepts overview

Five lessons, one question: did the model learn, or did it memorise?

  • a score on the training data proves nothing
  • error comes from bias, variance and noise
  • honest numbers need data the model never saw
01

Mental model

A model that copies every training row scores perfectly on them. Only new rows show whether it learned.

  • The training error says how well the model remembers; the error on new rows says how well it generalises.
  • Every lesson in this group is a way to get the second number right, or make it smaller.

The five lessons

One subsection per lesson, in reading order; each picture is the core of that lesson.

2.1Problem type

Numbers in the label column mean regression; classes mean classification — and the loss follows.

  • Lesson: Supervised, unsupervised & reinforcement.

2.2Bias and variance

Bias: wrong on average. Variance: jumps around from one training sample to the next.

E[error]expected error on new data=bias2too simple+variancetoo flexible+noiseno model can remove
  • Lesson: Bias–variance tradeoff.

2.3Data splits

Lock a test set away; rotate a validation fold through the rest and average the scores.

  • Lesson: Train / val / test & cross-validation.
  • Rows from the same customer or later dates must not leak across the split.

2.4Overfitting

As the model grows, training error keeps falling; validation error turns up once it starts memorising.

Ltotal=Ldatafit the training rows+λ ‖w‖2penalty for large weights
  • Lesson: Overfitting & regularization — learning curves, L1/L2, early stopping.

2.5Feature engineering

Raw columns become numbers: one 0/1 column per category, sizes rescaled to a common spread.

  • Lesson: Feature engineering — encoding, missing values, scaling.
  • Distance-based models (KNN, SVM) need scaling; trees do not.
