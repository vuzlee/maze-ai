Machine learning · Core concepts

Supervised, unsupervised & reinforcement

The first step of any ML problem is to name it. Three things to remember:

  • the kinds of learning differ by the feedback signal, not by algorithm
  • the label type picks the loss and the metric: a number or a class
  • labels are usually the expensive part, and there are standard ways around it
01

Mental model

Ask one question: what feedback does the model get — an answer per sample, nothing, or a late score?

1.1Supervised learning

Every training sample comes with the right answer, so each prediction can be scored.

  • Examples: spam filters, price prediction, image classifiers.
  • Labels give you a ruler, so try to turn a problem into a supervised one first.

1.2Unsupervised learning

No answers at all — the model can only find structure, such as groups.

  • Examples: clustering customers, dimensionality reduction, anomaly detection.
  • Cost: there is no score to say the groups are right.

1.3Reinforcement learning

An agent acts step by step and gets a reward, often only at the end.

  • Examples: game agents, robot control, the RLHF step of LLM training.
  • The hard part is credit assignment: which earlier action earned the reward.
02

Where labels come from

Labels are made, not found — and their cost decides whether a project is feasible.

2.1Logged by the system

The business process writes the label: returns, defaults, cancellations.

  • Almost free, but you wait for the outcome to happen.
  • The most common place for data leakage: a column filled in after the event.

2.2Labelled by hand

People tag each sample: medical images, document categories.

  • Expensive and slow; check how often two labellers agree before training.

2.3Inferred from behaviour

A rule turns behaviour into a label: watched to the end counts as liked.

  • Cheap and plentiful, but only approximate.
  • Biased by the running system: users can only click what they were shown.
03

Regression or classification

The type of label picks the loss and the metric, not the model.

3.1Regression

The label is a number: price, duration, temperature.

MSE = 1n Σaverage over n samples (yi − ŷi)2squared error of one sample
  • Same linear skeleton as Linear regression.
  • A star rating 1–5 is a number, but the gap 1→2 is not the gap 4→5 — it may be better treated as ordered classes.

3.2Classification

The label is one of k classes; the model outputs a probability, then a threshold picks the class.

log loss = −1n Σaverage [ yi log pitrue class is 1 + (1 − yi) log(1 − pi) ]true class is 0
  • Same skeleton as Logistic regression; MSE and log loss both come from maximum likelihood.
  • The threshold is a business decision — see Metric & confusion matrix.
  • Multi-class (exactly one class, softmax) differs from multi-label (several at once, one sigmoid each).
04

When labels are too expensive

Usual reality: lots of raw data, few labels. Each workaround squeezes a signal out of unlabelled data.

4.1Self-supervised learning

Hide part of the data and make the model guess it back; the hidden part is the label.

  • The basis of every language model's pretraining.

4.2Semi-supervised learning

A few labels spread to unlabelled neighbours as pseudo-labels, then training continues.

  • Use it with a few thousand labels and millions of samples.

4.3Transfer learning

Start from a model trained on a large dataset and train only a small new part.

  • Try this first for images and text: cheapest and usually good enough.

4.4Active learning

The model picks the samples it is least sure of and asks a human only for those.

  • Use it when the labelling budget is fixed.
