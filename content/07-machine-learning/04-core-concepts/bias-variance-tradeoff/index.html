Bias–variance tradeoff

The thread running through the whole shelf: almost every ML technique trades bias for variance or the other way round. This lesson splits error into three parts, then shows which technique targets which part.

01

Mental model

Retrain the same model on many different training sets and look at where its predictions land: off target together is bias, scattered is variance, and the truth itself still misses by the noise.

1.1Bias and variance on a target

Each shot is one retrained model: bias is how far the shots sit from the centre, variance is how widely they spread.

  • Too simple a model lands tight but off centre (underfitting); too flexible a model lands around the centre but scattered (overfitting).
  • The goal is the top-left cell: both small at once, which is why the two trade off.

1.2Noise

Even the true function misses every point by the noise in the labels.

  • Noise σ2 is a floor: two customers with identical features, one buys and one does not.
  • Once validation error sits on that floor, only new features help, not more capacity.
02

Error decomposition

Expected squared error splits into exactly three parts; the goal is the smallest total, not the smallest part.

E[(y − f̂(x))2]expected error = (E[f̂(x)] − f(x))2bias² + E[(f̂(x) − E[f̂(x)])2]variance + σ2noise
f(x)
the truth, fixed and unknown
f̂(x)
the learned model, different for every training set
E[·]
average over all training sets that could be drawn
  • Every regularization technique is the same deal: give up a little bias to win back a lot of variance.
  • The decomposition is exact for squared error; for other losses the same intuition holds.
03

Tradeoff curve

Push complexity up: bias falls, variance rises, and their sum is U-shaped. Stop at the bottom of the U.

  • "Complexity" is whatever the model exposes: polynomial degree, max_depth, number of layers, 1/λ.
  • In practice you cannot compute bias and variance; you read them from train and validation error — see Overfitting & regularization.
  • Very large neural networks show double descent: past the point where parameters exceed samples, test error falls again.
04

Which fix hits which term

Every fix moves one term down and often the other up. Diagnose first, then pick the fix.

4.1More data

Cuts variance; bias does not move.

  • Useless when the problem is bias — the learning curve tells you which, see Learning curves.

4.2Regularization

Trades a little bias for a lot less variance.

  • L1, L2, dropout and early stopping all live here: Regularization.

4.3Stronger model

More features or capacity: the reverse trade.

  • Boosting works on this side: each round cuts bias, so it needs early stopping before variance takes over.

4.4Bagging

Averaging many models trained on resamples cuts variance and keeps bias.

  • That is why Random Forest beats a single deep tree: see Tree family overview.
