Machine learning · Core concepts

Overfitting &
regularization

The model memorizes the data instead of learning the pattern. This lesson is the diagnosis and treatment: read the train–validation gap to see what is broken, read the learning curve to decide between more data and a stronger model, and pick the regularization that fits the problem.

01

Mental model

Same ten points, three models: a model can be too simple, about right, or memorize the noise. Only the validation points tell them apart.

  • Train error 0 is a warning, not a success: with 10 points a degree-9 polynomial can always hit them all.
  • Why simple and flexible models fail in opposite ways: Bias–variance tradeoff.
02

Diagnosis

Two numbers, train error and validation error, say what is broken; their curves over n say whether more data will help.

2.1Train vs validation error

Level of both numbers is bias, the gap between them is variance.

  • High train error with low validation error is not a model problem: check the split for leakage — see Train/val/test & cross-validation.

2.2Learning curve: gap that closes

Train and validation error against training set size: a big gap that shrinks means more data pays off.

2.3Learning curve: curves that meet too high

Curves that meet above the noise floor mean more data is wasted.

  • Read the gap, not the height: the straight line has lower error at small n, yet it is the model that should not get more data.
  • Labeling is expensive; this plot answers "are 10,000 more samples worth it" before you pay.
03

Regularization

Regularization deliberately constrains the model so it cannot memorize noise — paying a little train error for a lot less validation error.

Lreg = 1n Σ (ŷi − yi)2data loss: fit the points + λ Σ w2jL2 penalty: small weights
Lreg = 1n Σ (ŷi − yi)2data loss: fit the points + λ Σ |wj|L1 penalty: few weights
λ
regularization strength, chosen on validation data
wj
model weights; the intercept is not penalized

3.1L2 (weight decay)

Penalizing w2 shrinks every weight a little; the curve calms down.

  • Default for linear models and neural networks; in deep learning it is called weight decay.

3.2L1

Penalizing |w| drives some weights to exactly zero.

penalty = λ Σj |wj|sum of absolute weights
  • Use it when you suspect most features are useless. Penalty shapes and ElasticNet: Ridge, Lasso & ElasticNet.

3.3Early stopping

Watch validation error during training and stop at its minimum.

  • Works for any iterative method — boosting, neural networks — and adds no penalty term.

3.4Dropout

Switch off random neurons each training step, so no single path can memorize.

  • Only during training: forgetting to turn it off at inference makes predictions random. Covered in depth on the deep learning shelf.

3.5Data augmentation

Make plausible variants of each sample with the same label.

  • Images: flip, crop, rotate. Text: synonym swap, back-translation. Audio: time shift, noise.
  • Simpler still: reduce complexity (lower degree, smaller max_depth, fewer layers) — usually the first thing to try.
