Machine learning · Model evaluation

Metric & confusion matrix

A threshold turns scores into labels, the labels sort every row into four cells, and every classification metric is a ratio of those cells.

01

Mental model

Score, cut at a threshold, compare with the truth: each row lands in one of four cells.

  • TP caught, FN missed, FP false alarm, TN rightly left alone. confusion_matrix(y_true, y_pred) puts actual classes on the rows, predicted on the columns.
  • The model gives the score; the threshold is a separate choice on top of it — section 03.
02

Metrics from the cells

Each metric picks which cells go on top and which go underneath.

2.1Accuracy

The diagonal over everything: what share of rows are right.

accuracy = TP + TNTP + FP + FN + TNright rows over all rows
  • Counts TN like any other cell, so when negatives dominate it says little — section 04.

2.2Precision & recall

Both put TP on top; they differ in what they divide by — a column or a row.

2.2.1Precision

Down the predicted-pos column: of the rows I flagged, how many are truly pos.

precision = TPTP + FPpredicted-pos column
  • Pays for false alarms (FP): put it first when a wrong flag is expensive — blocking a real customer, spam-filtering a real email.

2.2.2Recall

Along the actual-pos row: of the truly pos rows, how many I caught.

recall = TPTP + FNactual-pos row
  • Pays for misses (FN): put it first when a miss is expensive — cancer screening, machine faults. Also called sensitivity or TPR.

2.3Specificity

Recall for the negatives: along the actual-neg row, how many I left alone.

specificity = TNTN + FPactual-neg row
  • Also TNR; 1 − specificity is the FPR, the x-axis of the ROC curve.
  • Balanced accuracy = (recall + specificity) / 2 weighs both classes equally.

2.4F1

One number for precision and recall: their harmonic mean, pulled toward the smaller one.

F1 = 2 P RP + Rharmonic mean ; Fβ = (1 + β2) P Rβ2 P + Rβ = 2: recall counts double
  • A model that is great on one and useless on the other cannot hide behind a plain average.
  • F1 still assumes an FP and an FN cost the same — rarely true; section 05 prices them instead.
03

Threshold

Raise the threshold and rows leave the predicted-pos column: precision tends up, recall goes down.

  • Recall can only fall as the threshold rises; precision usually rises but can dip, as from 0.6 to 0.35 here.
  • 0.5 is a library default, not a property of the model. Serve the score and keep the threshold in config.
  • Tracing every threshold gives the ROC and PR curves.
04

Imbalanced data

When one class is rare, saying "no" to everyone scores high accuracy and zero recall.

  • Ask for the class ratio before reading any number: at 95 : 5 the floor for accuracy is already 0.95.
  • Report precision, recall, PR-AUC or balanced accuracy instead; they never use TN as their only evidence.
05

Threshold by cost

Price each error, add up the bill at every threshold, keep the cheapest.

cost(t)bill at threshold t = cFP · #FP(t)price of a false alarm × count + cFN · #FN(t)price of a miss × count
  • A miss costing 3× a false alarm pushes the best threshold below 0.5, here to 0.175.
  • The answer is in money; when prices change, re-pick the threshold — no retraining. Pick it on validation data, not test.
06

Multiclass

K classes give a K × K matrix and one precision, recall and F1 per class.

6.1K × K matrix

Row = actual class, column = predicted: the diagonal is right, everything else is a confusion.

  • For one class, its column minus the diagonal is FP, its row minus the diagonal is FN — one-vs-rest.
  • Off-diagonal cells show which classes are mixed up: here every bird is called a cat.

6.2Averaging

Three per-class F1s become one number by macro, weighted or micro averaging.

  • macro exposes the failing rare class (0.49); weighted and micro let the big classes hide it.
  • For single-label tasks micro-F1 equals accuracy, so it inherits the flaw of section 04. Set with average="macro".
07

Regression metrics

The label is a number: every metric starts from the residual y − ŷ.

7.1MAE

Average length of the residuals, in the unit of y.

MAE = 1n Σi |yi − ŷi|mean absolute residual
  • Every unit of error counts the same, so one outlier moves it only in proportion.
  • MAPE divides each residual by |y|: it explodes near y = 0 and favours under-prediction.

7.2MSE & RMSE

Average area of the residual squares; the root brings it back to the unit of y.

MSE = 1n Σi (yi − ŷi)2mean squared residual ; RMSE = √MSEsame unit as y
  • Squaring makes one error of 8 weigh as much as 64 errors of 1: RMSE ≥ MAE, and the gap grows with outliers.
  • MSE is the loss most regressors minimise; minimising it predicts the mean, minimising MAE the median.

7.3R²

Squared error of the model against the squared error of always predicting the mean.

R2 = 1 − SSESSTΣ(y − ŷ)² over Σ(y − ȳ)²
  • Unitless, but SST is the spread of this test set: do not compare R² across two datasets.
  • It can be negative — the model is then worse than the constant ȳ.
