Probability calibration

A model is calibrated when, of all the rows it scores 0.7, about 70% really are positive — and many models that rank well are not.

01

Mental model

Bin the rows by score; in each bin compare the mean score with the share really positive.

  • That plot is the reliability diagram; on the diagonal the score means what it says.
  • Below the diagonal the model is over-confident, above it under-confident. This model is both, at opposite ends.
  • It is a third question after is the decision right and is the ranking right: AUC only sees order, so it cannot see this.
02

Scores for calibration

Two numbers summarise the diagram, both computed from the same 20 rows.

2.1Brier score

The mean squared gap between each score and its 0/1 label; lower is better.

Brierper-row squared error = 1n Σi (pi − yi)2score minus label, squared
  • No bins needed. It mixes calibration with how well the model separates, so a sharper model also lowers it.
  • brier_score_loss in scikit-learn; log loss is its sibling with a harsher penalty on confident mistakes.

2.2ECE

Expected calibration error: each bin's gap to the diagonal, weighted by its share of rows.

ECEpure calibration = Σb nbnshare of rows in bin b · | meanb − rateb |gap to the diagonal
  • The value depends on the bins: few rows per bin make it noisy, so with little data use equal-count bins.
  • calibration_curve returns the points of the diagram; ECE is the weighted sum of their gaps.
03

Skewed by design

The skew is predictable from how a model makes its score; logistic regression trains on log loss and comes out close to the diagonal.

3.1Naive Bayes

Correlated features are counted as independent evidence, so scores are pushed to 0 and 1.

  • Each copy of the same evidence multiplies the odds again — see Naive Bayes.

3.2Random forest

The score is a vote share, and trees rarely all agree, so scores are pulled to the middle.

  • Bagging averages away the extremes — see Random forest.

3.3SVM

The output is a distance to the boundary, not a probability at all.

  • SVC(probability=True) runs Platt scaling internally — see SVM.

3.4Boosting & deep nets

Training keeps pushing the loss down on the training rows, so scores get sharper than the truth.

  • Boosting adds trees that keep moving the score away from 0.5; long-trained neural nets do the same, saying 0.99 when the truth is 0.8.
04

Fixing it

Learn a monotonic map from old score to new probability; order is kept, so AUC does not change.

4.1Platt scaling

Fit one sigmoid on held-out scores; two parameters.

pcalibrated = σ( A s + B )A, B fit by log loss on held-out rows
  • Two numbers: a few hundred rows are enough. It can only fix an S-shaped skew — right for SVM and over-confident models.

4.2Isotonic regression

Fit the best non-decreasing step function; any monotonic skew.

minf Σi (yi − f(si))2squared error , f non-decreasingnever goes down
  • One step per pooled block: it bends to any shape, and with under ~1,000 rows it fits their noise — prefer Platt then.
  • Always fit the map on rows the model did not train on: on training rows it relearns the same over-confidence. CalibratedClassifierCV(method="sigmoid" | "isotonic") does this with cross-validation.
05

When it is needed

Calibrate when the number itself feeds a decision; if only the order is used, skip it.

act if p · gainexpected value > costhere 5 · p > 4
  • Expected cost, thresholds set from money, risk scores shown to people, inputs to another model: calibrate.
  • Top-k lists and AUC: the order is all that is used, and calibration never changes it.
