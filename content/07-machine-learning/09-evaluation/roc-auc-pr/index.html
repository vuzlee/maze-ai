ROC-AUC & PR curve

Slide the threshold down a table of scores one row at a time, turn every confusion matrix into one point, and the points trace two curves that judge the ranking without fixing a threshold.

01

Mental model

A model gives scores; a threshold turns them into one confusion matrix, and the matrix into one point.

  • Ten predictions, sorted by score: four true positives (y = 1), six negatives. The same table drives every figure below.
  • Rows above the line are predicted positive. Lower the line and more rows cross it: one matrix, one point per position — counts and rates as in Metric & confusion matrix.
  • The curves judge the ranking only; picking the threshold is still a cost decision, and trusting the scores as probabilities is Probability calibration.
02

Threshold sweep

Step the threshold down one row at a time; each step moves one row into the predicted-positive column.

2.1ROC curve

Plot TPR against FPR: a positive row steps the curve up, a negative row steps it right.

TPR = TPTP + FNshare of positives caught , FPR = FPFP + TNshare of negatives flagged
  • Both rates divide within one class: TPR by the 4 positives, FPR by the 6 negatives.
  • The diagonal is a random ranking; a perfect one goes straight up to (0, 1) first.

2.2PR curve

Plot precision against recall from the same steps: a negative row only pulls precision down.

recall = TPTP + FNsame as TPR , precision = TPTP + FPshare of flags that are right
  • At the first step there is no point: nothing is flagged yet, so precision is 0/0.
  • The baseline is the positive rate, here 4/10 = 0.40 — flag everything and precision equals it. It is not 0.5.
03

Area under the curve

Each curve shrinks to one number: the area under it.

3.1ROC-AUC as area

Each negative adds a strip whose height is the positives already passed.

  • 0.5 is a random ranking, 1 a perfect one; roc_auc_score computes it.

3.2ROC-AUC as ranking

AUC is the chance that a random positive is scored above a random negative.

  • Each column of the grid is one strip of the area: the same 21 of 24, read as pairs.
  • Only the order of the scores matters; squash or stretch them and AUC does not move. A tie counts half.

3.3Average precision

Each positive adds a strip of width 1/4 whose height is the precision at that row.

APaverage precision = Σk (Rk − Rk−1)recall step, 1/4 at each positive · Pkprecision at that row
  • average_precision_score computes exactly this sum; it is the usual "PR-AUC" and avoids the optimistic straight-line interpolation of auc(recall, precision).
  • Compare it with the baseline, not with 0.5: 0.30 on data with 1% positives is a strong model.
04

Rare positives

Add many more negatives and ROC does not move, while precision and the PR curve fall.

  • FPR divides by the negatives, so ten times more false alarms on ten times more negatives is the same rate; precision counts the alarms themselves.
  • When positives are rare and every alert costs work — fraud, disease, search — report AP; ROC-AUC reads "excellent" while most alerts are wrong.
  • ROC-AUC is comparable across datasets with different class ratios; AP is not, because its baseline moves with the ratio.
