Model evaluation overview

One table of predictions answers three separate questions — is the order right, is the cut right, are the probabilities right — and each needs its own metric.

01

Mental model

"Is the model good" is three questions; change the scores without changing their order and only one answer stays put.

  • Every metric in this group reads the same table: id, true label, score.
  • A model can rank well and still be badly calibrated, or calibrated and badly cut — report the metric that matches how the score is used.
02

Three questions

Same ten rows, rearranged three ways: sorted, cut, binned.

2.1Ranking

Are the 1s above the 0s? Uses only the order of the scores.

  • ROC-AUC = the chance a random 1 scores above a random 0 — here 21 of 24 pairs.
  • No threshold involved; with rare positives read the PR curve instead — ROC-AUC & PR curve.

2.2Decision

Is the cut in the right place? Uses one threshold, then counts.

  • Every count metric — accuracy, precision, recall, F1 — comes from these four cells.
  • Move the threshold and all of them change — Metric & confusion matrix.

2.3Probability

Does a score of 0.8 mean 8 in 10 are 1? Uses the score value itself.

  • ECE = the bin-size-weighted gap between dot and diagonal; log loss and Brier score also judge the values.
  • Fixing it does not change the order — Probability calibration.
03

Choosing a metric

Task type first, then one question about the data, gives the main metric.

  • With rare positives ROC-AUC stays high because its false-positive rate divides by the huge pile of 0s.
  • When the score feeds a later calculation (pricing, risk), add log loss or Brier score; when FP and FN have known costs, minimise expected cost.
  • Measure on data the model never saw — Train, validation & test.
04

Offline to online

Every metric above is offline: it scores the model, not the product.

  • A higher AUC often fails to move the product; check early that the offline metric tracks the business one.
  • Whether the gap is real or noise is a statistics question — A/B testing.
