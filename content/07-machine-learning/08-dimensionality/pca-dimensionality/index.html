PCA & dimensionality reduction

PCA turns the axes toward the directions the data spreads most, then drops the thin directions, so a few new columns carry almost everything the old ones said.

01

Mental model

Turn the axes until the first one lies along the widest spread; keep the first few new columns.

  • Eight people, height x1 and weight x2: two columns that mostly say one thing, "how big".
  • The new columns z1, z2 are the principal components; together they lose nothing, z1 alone loses 2%.
  • No labels are used: PCA is unsupervised, it only looks at how the columns spread.
02

Centring

Subtract each column's mean first, so every direction is measured from the middle of the cloud.

  • The axes PCA finds pass through the origin; without centring PC1 would point at the mean instead of along the spread.
  • scikit-learn's PCA centres for you; it does not scale (see Standardising).
03

Principal components

Each component is a direction; each row's new value is where it lands on that direction.

3.1Direction of most spread

PC1 is the line whose shadows of the points are spread out the most.

  • Spread is measured as the variance of the feet on the line; at 0° it is just var x1, at 90° var x2.
  • Most spread is the same line as smallest perpendicular distance to the points — two views of one answer.

3.2Projection

Drop every point onto PC1 at a right angle; its position along the line is its score.

z1score of a row = v1 · xdot product with the unit direction = 0.59 x1 + 0.81 x2for these eight people
  • Two columns in, one column out: fit_transform returns exactly this z1 column.
  • New rows use the same v1 and the training mean: fit on the training set only, or the test set leaks in.

3.3Second component

PC2 is the widest direction at a right angle to PC1, and so on for PC3, PC4…

  • With d columns there are d components, each perpendicular to all before it.
  • The scores of different components are uncorrelated: what one says, no other repeats.
04

Covariance & eigenvectors

The scan in 3.1 is not needed: the components fall straight out of one small matrix.

4.1Covariance matrix

A d × d table of how every pair of centred columns moves together.

Ccovariance matrix = 1n − 1 XTXX centred, n rows = [ 67.7  87.4 ;  87.4  123.7 ]height, weight
  • Diagonal: the variance of each column. Off-diagonal: the covariance; large and positive here because tall people weigh more.
  • Symmetric, so its eigenvectors are perpendicular — that is why the components are.

4.2Eigenvectors

The directions C only stretches are the components; the stretch is their variance.

C vkmatrix times direction = λk vksame direction, stretched , λ1 = 187.5,  λ2 = 3.9sorted largest first
  • λ1 is exactly the peak of the curve in 3.1; v1 = (0.59, 0.81) is the line at 53.9°.
  • In practice it is computed by SVD of the centred table, X = UΣVT: the rows of VT are the components, without ever forming C.
05

Number of components

Each eigenvalue is the variance one component carries; keep components until enough of the total is kept.

5.1Explained variance ratio

A component's share is its eigenvalue over the sum of all eigenvalues.

ratiokshare of component k = λkΣj λjtotal = sum of column variances = 187.5191.4 = 98.0%PC1 here
  • The eigenvalues add up to the total variance of the original columns: nothing is created or lost by turning the axes.
  • scikit-learn: explained_variance_ratio_.

5.2Scree & cumulative curve

Plot the shares largest first; keep the smallest k whose running total passes 95%.

  • PCA(n_components=0.95) applies this rule; 90–99% are all common, the right one depends on what comes next.
  • The elbow of the scree plot, where bars stop shrinking fast, is the eyeball version of the same choice.
  • For plotting, keep 2 or 3 whatever they explain.
06

Reconstruction error

Map the kept scores back to the original columns; the gap to the real rows is exactly the dropped variance.

x̂reconstructed row = μ + Σk ≤ K zk vkmean + kept components , 1n − 1 Σi ‖xi − x̂i‖2 = Σk > K λkerror = dropped eigenvalues
  • PCA is the linear map that makes this error smallest for a given K — the loss it minimises.
  • inverse_transform does the trip back; a large error on one row flags it as unusual (a simple anomaly score).
  • Dropping components helps a model only when what is dropped is mostly noise; nothing guarantees that.
07

Standardising

Variance depends on units, so PCA does too: put every column on one scale first.

7.1Mixed units

Write height in millimetres and its variance grows 100 times; PC1 turns onto height.

  • The people did not change, only a unit: PCA is answering "which column has the biggest numbers".
  • The most common PCA mistake, and a silent one: it still runs and still prints 99% explained.

7.2Standardised

Divide each centred column by its standard deviation; every column has variance 1 and counts equally.

  • Same as PCA on the correlation matrix: here r = 0.96, so PC1 keeps 98% (λ = 1.96 of 2).
  • StandardScaler then PCA in one Pipeline, fitted on the training rows only.
08

PCA is not feature selection

Feature selection keeps some original columns; every PCA column is a weighted mix of all of them.

  • The weights, the loadings (components_), say how much each column feeds a component; a name like "size" for PC1 is a guess, not a fact.
  • Every original column must still be measured to compute z1, and tree models gain little from it — use selection when column names must survive.
  • PCA only finds straight directions; t-SNE and UMAP unfold curved structure into a 2-D picture, for looking only — their axes and distances mean nothing for a model.
