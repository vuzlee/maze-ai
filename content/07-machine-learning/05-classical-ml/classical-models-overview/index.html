Classical models — lookup table

None of these six models was created to fix another. They are six different assumptions about the shape of the data — choosing a model means choosing an assumption.

01

Mental model

Every model takes the same table and returns the same kind of prediction; they differ only in the family of shapes f is allowed to take.

  • So read the lookup table by the Believes that… column first: which assumption does your data look like?
  • The plots below the panels: on the ring, 100× more data leaves the linear model flat near 50% while 5-NN climbs past 99% — change the model, not the data size.
  • A loose assumption (KNN) bends anywhere but pays in variance and needs more data as dimensions grow — bias–variance seen from model choice.

Lookup table

Fit all six on the same data and the assumption becomes visible: only two of them can bend around curved classes.

  • All six need scaled features (Naive Bayes the least) — the group's most common silent bug; see Feature engineering.
  • On large tabular data all six usually lose to tree ensembles; they stay as baselines and as the place the core ideas first appear.
