Classical models overview

None of these six models was created to fix another. They are six different assumptions about the shape of the data — this page is the map; each picture opens its lesson.

01

Six pictures

Each model is one picture you can draw from memory: a line, an S-curve, shrunk weights, a margin, a circle of neighbours, a bell per class.

  • The picture is the assumption: a model can only fit data that looks like its picture.
02

Which model

Two questions pick the model: what is the label, then what does the data look like.

  • All six need scaled features (Naive Bayes the least) — the group's most common silent bug; see Feature engineering.
  • On large tabular data all six usually lose to tree ensembles; they stay as baselines.
