Classical models — lookup table

None of these six models was created to fix another. They are six different assumptions about the shape of the data — choosing a model means choosing an assumption.

01

Mental model

Every model in this group takes the same data table and returns the same kind of prediction. The only difference is the shape it believes the relationship between features and label has.

  • When the assumption fits, the model works well with very little data — left column, 88% with just 50 samples.
  • When the assumption is wrong, no amount of data saves it; you must change the model, not collect more data.
  • So the right question is not "which model is strongest" but "which assumption does my data look most like".
  • The price of a loose assumption: 5-NN wins big in the right column but loses in the left column at 50 samples — that is bias–variance seen from the side of model choice.
02

Lookup table

Read the Assumption column first — if it does not hold for your data, you don't need to read the next two columns.

  • Only KNN and kernel SVM can draw curved boundaries — the other four are all hyperplanes, so they all lose in the right column of the figure above.
  • Every model here requires feature scaling — the group's most common silent bug. See Feature engineering.
  • On large tabular data, all six usually lose to tree ensembles. Still worth learning: the core concepts show up as formulas.
03

Learning order

The first two lessons are required and must be read in order — the other four can be read in any order.

1 · Linear regressionWhere loss functions, gradient descent and meaningful coefficients first appear as formulas.
2 · Logistic regressionThe same linear model; change the wrapping function and the loss, and regression becomes classification.
3 · Ridge, Lasso & Elastic NetPenalizing coefficient size — an idea you will meet again in SVM, boosting and every neural network.
4 · SVMRead after Ridge, because the maximum margin is L2 expressed in geometry.
5 · KNNThe cleanest example of high variance and of the curse of dimensionality.
6 · Naive BayesStraight from Bayes to a classifier, with no optimization. The baseline for text.
