Machine learning · Classical models

SVM

Infinitely many lines separate two classes. SVM picks the one with the widest empty band. Three things to remember:

  • only a few points near the edge decide the line
  • a wide margin is regularization
  • the kernel trick gives curved boundaries without computing coordinates
01

Mental model

SVM picks the line in the middle, farthest from both sides. That empty band is called the margin.

  • This lesson uses its own set of 18 two-dimensional points, not the 6 customers A–F.
  • Why: with 6 points every point is a support vector, and the figure loses its meaning.
  • Logistic regression picks the line with the smallest log loss. If the data separates perfectly, infinitely many lines tie.
  • SVM changes the criterion: pick the line with the widest margin, so only one line remains.
  • Maximizing the margin is minimizing ‖w‖², exactly the L2 in Ridge.
02

Support vector

Only the points near the margin decide the line. Remove all the rest and the line does not move an inch.

  • Here only 3 of 18 points are support vectors. Prediction needs only them.
  • Very different from linear regression or Naive Bayes, where every sample contributes to the solution.
  • Good: the model is compact, prediction is fast. Bad: very sensitive to noise near the boundary.
  • With a wide margin, a slightly shifted new point is still classified right. That is regularization.
03

General formula

The first half keeps the margin wide. The second half penalizes points that intrude. C trades one off against the other.

L = ‖w‖22wide margin, which is L2 + C · Σ max(0, 1 − yi·F(xi))hinge loss: penalizes points not yet past the band
‖w‖
length of the coefficient vector. Half the band is exactly 1/‖w‖, so the shorter w is, the wider the band
y·F(x)
the margin of one point. 1 or more means it is past the band
C
how hard 1 unit of intrusion is penalized
  • Here ‖w‖ = 1.030 so the band is 1.94 wide, and Σ hinge = 0.94.
  • Hinge hits 0 exactly at margin = 1. Points past that mark add exactly 0 to the loss.
  • What we really want is to count misclassified points, but its derivative is 0 everywhere. Hinge is the sloped substitute.
  • Hinge penalizes linearly, so SVM tolerates label noise better than AdaBoost with exponential loss.
04

C and gamma

Hard margin forbids any intrusion. Soft margin allows it with a penalty. Real data always uses soft.

  • Small C gives a wide margin (2.30) and 5 support vectors. Very large C gives a narrow margin (1.03) and 3.
  • C going to infinity forbids intrusion, i.e. hard margin.
  • C sits exactly where the inverse of λ sits in Ridge. Same trade-off axis, just written differently.
  • Choose both by cross-validation on a two-dimensional grid, on a log scale.
05

Kernel trick

If 2 dimensions cannot separate the data, lift it into more dimensions. The kernel skips computing coordinates altogether.

Three common kernels, and why RBF is infinite-dimensional:

  • SVM only uses dot products between pairs of points, it never needs coordinates in the new dimensions.
  • RBF coordinates cannot be computed at all, so the kernel trick is the only way to use it.
06

Pros and cons

Every strength comes from keeping only a few support vectors. Every weakness comes from exactly the same place.

AspectGainLoss
Sample sizeFits well even with few samplesChokes beyond a few tens of thousands, because of the n×n matrix
DimensionalityMany dimensions are no problemStill hit by the curse of dimensionality with an RBF kernel
ModelCompact, prediction needs only the support vectorsWith a kernel, nothing interpretable can be read out
BoundaryCan curve thanks to the kernelC and gamma must be tuned together
NoiseHinge penalizes linearly, so it handles label noise fairly wellVery sensitive to noise right near the boundary
OutputGives distance to the boundaryNo probabilities, needs extra calibration
  • Choose SVM for few samples and many dimensions, e.g. gene data or vectorized text.
  • Choose gradient boosting for medium-sized tabular data when you need the highest accuracy.
  • Choose logistic regression when you need trustworthy probabilities.
  • Common mistakes: forgetting to standardize features, and tuning C and gamma one after the other instead of together.
