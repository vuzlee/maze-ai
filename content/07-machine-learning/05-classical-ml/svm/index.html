Machine learning · Classical models

SVM

Many lines separate two classes. A support vector machine keeps the one with the widest empty band around it.

  • only the few points touching the band decide the line
  • a wide band is the L2 penalty in disguise
  • a kernel bends the line without computing new coordinates
01

Mental model

Of all lines that separate the classes, SVM keeps the one farthest from both sides. The empty band around it is the margin.

  • The points touching the band edges are the support vectors; they alone fix the line.
  • Logistic regression on separable data has no unique best line; the widest-band rule picks exactly one.
02

General formula

A linear score, a sign for the class, and a loss that trades band width against points inside the band.

F(x) = w · xweighted sum of features + bbias , ŷ = sign F(x)class +1 or −1
L = ‖w‖22wide band (L2) + Cprice of intrusion · Σi max(0, 1 − yi F(xi))hinge: points not yet past the band
  • The band edges are where F = ±1, so the width is 2 / ‖w‖: maximizing the band is minimizing ‖w‖², the same penalty as Ridge.
  • y · F(x) is a point's margin: 1 or more means it is past the band.
03

How it learns

Score every point, take its margin, and charge hinge only to points that are not yet past the band.

  • Hinge is 0 from margin 1 onward, so most points cost nothing and drop out of the solution.
  • The penalty grows linearly with intrusion, so one mislabelled point cannot dominate the loss.
  • The solver (SMO in scikit-learn's SVC) finds the w, b with the smallest L.
04

Key knobs

Which points matter, how much intrusion is allowed, and how the line bends.

4.1Support vectors

Remove every point that does not touch the band and train again: the line does not move.

  • The model stores only the support vectors, so prediction is cheap.
  • The flip side: a single noisy point near the boundary can move the whole line.

4.2C — soft vs hard margin

Large C forbids intrusion and narrows the band; small C allows it and widens the band.

  • C → ∞ is the hard margin: no point may enter the band. Real data always uses a soft margin.
  • C plays the role of 1/λ in Ridge: large C overfits, small underfits.

4.3Kernel trick

Data no line can split may split cleanly after adding a dimension; a kernel does this without ever computing it.

K(a, b)kernel = φ(a) · φ(b)dot product in the lifted space = exp(−γ ‖a − b‖2)RBF, the default
  • The solver only needs dot products between pairs of points, so a function K can stand in for the lifted coordinates.
  • Common kernels: linear, polynomial (a·b + 1)d, and RBF, whose lifted space is infinite-dimensional.

4.4Gamma

γ sets how far one point's influence reaches in the RBF kernel: small is smooth, large is one spike per point.

  • Large γ memorizes the training set and fails between points: overfitting.
  • Tune C and γ together on a log grid with cross-validation.
05

Where it breaks

Everything rests on distances between points and on comparing every pair of points.

5.1Unscaled features

The margin is a distance, so the feature with the largest unit takes over.

  • Always put a StandardScaler before SVC in the pipeline.

5.2Large datasets

A kernel SVM compares every pair of points, so cost grows with n².

  • SVM shines with few samples and many features (text, genes); medium tabular data usually goes to gradient boosting.

5.3No probabilities

SVM returns a distance to the line, not a probability; a sigmoid fitted afterwards converts it.

  • When calibrated probabilities matter, prefer logistic regression or see Calibration.
  • With a kernel there are no readable coefficients either.
