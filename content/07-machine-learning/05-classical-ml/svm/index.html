Machine learning · Classical models

SVM

Many lines separate two classes. A support vector machine keeps the one with the widest empty band around it.

  • only the few points touching the band decide the line
  • a wide band is the L2 penalty in disguise
  • a kernel bends the line without computing new coordinates
01

Mental model

Of all lines that separate the classes, SVM keeps the one farthest from both sides. The empty band around it is the margin.

  • Logistic regression on separable data has no unique best line; the widest-band rule picks exactly one.
  • A wide band is regularization: a slightly shifted new point still lands on the right side.
02

Hyperplane & margin

The line is a hyperplane w · x + b = 0; the margin is the band between the two parallel lines where the score is ±1.

2.1Decision function

Every point gets a score F(x); its sign says which side of the line it is on.

F(x) = w · xweighted sum of features + bbias , ŷ = sign F(x)class +1 or −1
  • SVM returns a score (a signed distance), not a probability; a sigmoid fitted afterwards (Platt scaling, SVC(probability=True)) converts it — or use logistic regression, see Calibration.

2.2Margin width

The band edges are F = ±1, so the band is wider when ‖w‖ is shorter.

margin = 2‖w‖shorter w, wider band
  • Widest band = smallest ‖w‖², the same penalty as Ridge.
  • The margin is a distance, so the feature with the largest unit dominates it: standardize features (StandardScaler) before SVC.

2.3Support vectors

Remove every point that does not touch the band and train again: the line does not move.

  • The model stores only the support vectors (3 of 18 here), so it is compact and prediction is fast.
  • The flip side: a single noisy point near the boundary can move the whole line.
03

Hard & soft margin

Hard margin forbids any point inside the band. Soft margin allows it and charges a penalty. Real data always uses soft.

3.1Hard margin

Widest band such that every point is on its own side and past the band.

min ‖w‖22widest band s.t. yi F(xi) ≥ 1every point past the band
  • Works only when the classes separate perfectly; one mislabelled point leaves no solution.

3.2Soft margin & hinge

Score every point, take its margin y · F, and charge hinge only to points not yet past the band.

L = ‖w‖22wide band (L2) + Cprice of intrusion · Σi max(0, 1 − yi F(xi))hinge
  • Hinge is 0 from margin 1 onward, so points past the band cost nothing and drop out of the solution.
  • Counting mistakes has zero slope everywhere; hinge is its sloped stand-in, and it grows linearly, so label noise hurts less than with AdaBoost's exponential loss.

3.3C

Large C makes intrusion expensive: narrow band, close to hard margin. Small C makes it cheap: wide band.

  • C plays the role of 1/λ in Ridge: large C overfits, small underfits; C → ∞ is hard margin.
  • Tune C (and γ for RBF) together on a log grid with cross-validation.
04

Kernel trick

The solver only needs dot products between pairs of points, so a function K(x, x′) = φ(x) · φ(x′) can stand in for lifting the points into more dimensions.

  • A kernel compares every pair of points: an n × n matrix, so training slows down sharply beyond a few tens of thousands of rows. SVM shines with few samples and many features (text, genes); medium tabular data usually goes to gradient boosting.

4.1Linear kernel

No lift at all: the score stays linear in x, so the boundary is straight.

K(x, x′) = x · x′plain dot product

4.2Polynomial kernel

Adds squared and cross terms. Two rings no line can split sit at different heights after adding x12 + x22, and a flat plane separates them.

K(x, x′) = (x · x′ + c)ddegree d
  • Degree 2 in 2D already means 6 terms: 1, x1, x2, x12, x22, x1x2; the kernel never writes them out.

4.3RBF kernel

At heart an infinite Taylor series: one polynomial kernel of every degree, summed — so it works in infinitely many dimensions without ever building them.

K(x, x′) = e−γ‖x − x′‖2 = e−γ‖x‖2e−γ‖x′‖2one point each · e2γ x·x′expand by Taylor
e2γ x·x′ = ∞Σk = 0 (2γ)kk! (x·x′)ka polynomial kernel of every degree k → infinitely many dimensions
  • No coordinate vector can hold infinitely many dimensions; the kernel gets the dot product in one step, which is the whole point of the trick.

4.4Gamma

Seen from the data, each training point puts a bump around itself and the score is their sum; γ sets how wide each bump is.

  • Small γ: wide bumps, a smooth boundary. Large γ: a spike on every point, memorises the training set (overfitting). RBF is the default kernel in SVC.
