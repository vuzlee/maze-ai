Ridge, Lasso & Elastic Net

Keep the old loss and add a term that penalizes coefficient size. Three things to remember:

  • Ridge (L2) shrinks coefficients toward 0
  • Lasso (L1) sets some coefficients exactly to 0
  • Elastic Net combines both
01

Mental model

With many features, the fastest way to cut training error is to memorize the noise, and the coefficients blow up. The penalty narrows where the coefficients are allowed to sit.

  • Running example: 6 customers, 4 standardized columns.
  • The first two columns say almost the same thing; the last two are noise.
  • Without a penalty the coefficients reach 32. Change a few samples and they jump to completely different values.
  • This mechanism also shows up in Logistic regression (parameter C), neural networks (weight decay) and XGBoost (λ on leaf values).
02

General formula

Add a term penalizing coefficient size to the loss. That is regularization.

Ridge · L2 = L + λ Σ wj2coefficients evenly small, not 0
Lasso · L1 = L + λ Σ | wj |some coefficients exactly 0
Elastic Net = L + λ1 Σ | wj | + λ2 Σ wj2both combined
L
the original loss, usually squared error
wj
the coefficient of feature j
λ
penalty strength, chosen by cross-validation
  • No penalty: coefficients −29.3 and +32.0. Ridge brings them to around 1.1.
  • Lasso keeps only 1/4 columns: that is sparse, see section 03.
  • RMSE barely changes across methods: 2.25 vs 2.31 vs 2.58.
  • Standardize features before penalizing. Otherwise a column in small units gets penalized unreasonably hard.
  • Do not penalize the intercept: it only shifts the line, it does not make the model more complex.
03

Why L1 hits exactly 0 · sparse coefficient vector

The diamond's corners lie right on the axes, so the L1 solution lands where one coefficient is exactly 0. A coefficient vector with many zero entries is called sparse.

  • The diamond has corners because |w| is not differentiable at 0. The picture and the derivative tell the same story.
  • An entry exactly 0 means the model does not read that feature when predicting.
  • This property is also called embedded feature selection: features are selected during training itself.

The weak side of sparsity: which features get chosen is unstable.

  • Within a group of correlated features, Lasso picks one arbitrarily.
  • So do not read the list of features Lasso keeps as a verdict on importance.
04

Elastic Net: mixing L1 and L2

Elastic Net adds both penalty terms. l1_ratio decides how much L1 goes into the mix.

Elastic Net = Loriginal loss + α · ρ · Σ | wj |L1 part: exactly to 0 + α · 1 − ρ2 · Σ wj2L2 part: shrinks the group together
α
overall penalty strength, plays the role of λ
ρ
l1_ratio, from 0 (all L2) to 1 (all L1)
  • l1_ratio = 0 keeps all 4/4 columns. l1_ratio = 1 keeps only 1/4.
  • In between: the two correlated columns are kept together, the two noise columns are dropped. That is where Elastic Net beats pure Lasso.
  • The price: two hyperparameters to tune instead of one.
  • Use it when features are correlated in groups, or when there are more features than samples.
05

λ: penalty strength

λ is the only hyperparameter worth tuning. Raising λ trades variance for bias.

  • λ is very sensitive: λ = 0.01 already brings the coefficients down to 2.78 with RMSE only 2.28.
  • It fixes how trustworthy the coefficients are, not the error. Only λ = 100 pushes RMSE up to 3.09.
  • Sweep λ on a log scale. A linear sweep completely misses the small-value range.
  • Choose λ on a validation set or by cross-validation, never on the test set.
06

Pros and cons

All three fight overfitting. They differ in the weakness that comes with them.

AspectRidge · L2Lasso · L1Elastic Net
Sets coefficients exactly to 0No, keeps every featureYesYes
Group of correlated featuresThe whole group shrinks togetherPicks one arbitrarily, drops the restThe whole group shrinks together
More features than samplesWorksCan select at most n featuresNo limit of n
SolutionClosed-form formulaMust be solved iterativelyMust be solved iteratively
HyperparametersOne, λOne, λTwo, strength and mixing ratio
List of kept featuresProduces no listA little data change gives a different listMore stable than Lasso
  • Choose Ridge when many features each help a little, or you need coefficients that stay stable under multicollinearity.
  • Choose Lasso when you suspect most features are useless and they are weakly correlated with each other.
  • Choose Elastic Net when features are correlated in groups, or there are more features than samples.
  • Common mistakes: not standardizing before penalizing, reading the C parameter backwards, and trusting the feature list Lasso picks.
