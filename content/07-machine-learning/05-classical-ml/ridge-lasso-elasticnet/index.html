Machine learning · Classical models

Ridge, Lasso & Elastic Net

Keep the linear model, add one term to the loss that charges for large weights. The shape of that term decides whether weights shrink or vanish.

01

Mental model

With correlated or noisy features, the error-only fit hides the data in huge weights that cancel each other. A penalty on weight size pulls them back.

  • Running example: 6 standardized rows; x1 and x2 are the same income in two units, x3, x4 are noise.
  • Huge cancelling weights flip wildly when a few rows change: that is high variance (Bias–variance tradeoff).
  • The same idea is weight decay in neural networks and λ on leaf values in XGBoost.
02

General formula

The loss is the old error plus λ times a penalty on the weights. Only the penalty changes between the three methods.

J(w)what training minimizes = Σ (yi − ŷi)2squared error, as in linear regression + λpenalty strength ≥ 0 · P(w)penalty on weight size
PRidge = Σ w2jL2: shrinks all · PLasso = Σ |wj|L1: zeros some · PEN = ρ Σ |wj| + 1 − ρ2 Σ w2ja mix of both

With one feature, ridge has a closed form you can do by hand: λ is simply added to the denominator.

  • λ = 0 gives back plain linear regression; λ → ∞ drives every weight to 0.
  • The intercept is not penalized: it only shifts the line, it adds no complexity.
  • In scikit-learn λ is called alpha; in LogisticRegression it is C = 1/λ, so larger C means a weaker penalty.
03

Three penalties

Picture the penalty as a region the weights must stay inside; the answer is where the smallest error contour first touches it.

3.1Ridge · L2

The region is a circle: smooth everywhere, so the touching point is almost never on an axis — every weight shrinks, none becomes 0.

  • Correlated features share the weight evenly (0.71 and 0.70 in section 01).
  • Has a closed form, so it is fast; trade-off: it never drops a feature.

3.2Lasso · L1

The region is a diamond with corners on the axes; the contour usually touches a corner, where one weight is exactly 0.

  • A weight of exactly 0 means the feature is not used: selection happens during training (a sparse model).
  • No closed form: solved iteratively (coordinate descent). Trade-off: at most n features kept when features outnumber rows.

3.3Elastic Net

A mix set by ρ (l1_ratio): the L1 part zeros useless features, the L2 part keeps correlated twins together.

  • ρ = 0 is ridge, ρ = 1 is lasso.
  • Use it when features come in correlated groups or outnumber rows; trade-off: two knobs to tune instead of one.
04

Knobs

Two settings decide whether the penalty helps: how strong it is, and what units the features are in.

4.1Penalty strength λ

Small λ already tames the weights while the error barely moves; large λ flattens everything.

  • Sweep λ on a log scale (0.001, 0.01 … 100); a linear sweep skips the useful small values.
  • Pick λ by cross-validation (RidgeCV, LassoCV), never on the test set — see Train/val/test & CV.

4.2Standardize first

The penalty charges the raw weight, so a feature in small units needs a big weight and gets crushed for its unit alone.

  • Scale every feature to mean 0, std 1 before fitting (StandardScaler in a pipeline).
  • Fit the scaler on the training split only, then apply it to validation and test.
05

Where it breaks

The penalty buys stable predictions; it does not buy trustworthy feature choices or a free lunch at any λ.

5.1Lasso flips between twins

With two correlated features lasso keeps one arbitrarily; a small change in the data swaps which.

  • Do not read lasso's kept list as "the important features".
  • Fix: Elastic Net keeps the group together, or check stability across bootstrap refits.

5.2Too much penalty underfits

Past the sweet spot, λ outweighs the data and the model drifts toward predicting the mean.

  • Rising validation error at large λ is bias, not variance (Overfitting & regularization).
  • A penalty cannot fix a model that is too simple: a curve still needs curved features.
