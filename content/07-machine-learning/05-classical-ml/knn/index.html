Machine learning · Classical models

KNN — k nearest neighbors

It learns nothing, it only remembers. Three things to remember:

  • find the k nearest rows, then take the majority
  • no parameters are learned
  • scaling is mandatory, or the large-scale column drowns out the rest
01

Mental model

To predict a new row: find the k rows most like it in the existing data, then combine them.

How to combine the k neighbor, by task:

TaskCombine byUse when
Classificationmost-voted classdiscrete labels
Regressionmean of k neighborcontinuous values
Regression with outliersmedian of k neighborlong-tailed data
  • No parameters are learned, so it is called a non-parametric model or a lazy learner.
  • For the same reason KNN has no global objective function: no gradient, no early stopping.
  • It flips the cost compared with every other model: training costs almost nothing, prediction costs a lot.
  • Each prediction costs O(n·d). Large datasets need an index, e.g. a KD-tree or HNSW in a vector database.
02

From table to prediction

It is just sorting by distance, then taking the first k rows and counting votes.

  • New customer X: age 25, income 35M.
  • Three values of k give three different outcomes, so k is the model's only tunable knob.
  • The decision boundary has no fixed shape; it follows the data.
  • Strong when the true relationship is wiggly, weak when the data is noisy.
03

Classification or regression

Same k neighbor, same distance. Only the combining step changes: classification takes a vote, regression takes the mean.

classification : ŷ = mode(yj)vote: the most-voted class among the k neighbor
regression : ŷ = 1k Σj ∈ Nk yjmean: average of the k neighbor
Nk
the set of k nearest neighbor of the row being predicted
yj
label or value of the j-th neighbor
mode
the most frequent value
  • With k = 3: vote gives no, while mean gives 2.33.
  • Customer E has value +7, so the mean sits far from the median 1.00.
  • For long-tailed data use the median instead of the mean, the same story as MAE vs MSE in Linear regression.
  • In sklearn: KNeighborsClassifier votes, KNeighborsRegressor takes the mean.
04

Choosing k and the metric

"Close" is not given. Choosing the metric is choosing the model, and you must scale first.

k sits right on the bias–variance axis:

kBoundaryTrade-off
k = 1hugs every point, memorizes the noise toohigh variance, low bias
moderate kchosen by cross-validationtrades detail for stability
k = nalways predicts the majority classhigh bias, low variance
  • With k = 1, training error is 0 because each point is its own neighbor. That number is meaningless.
  • For two-class problems pick an odd k to avoid ties. k is usually swept from 1 to 30.
  • Votes can be weighted by distance, which makes a large k less harmful.
  • Trees compare one column at a time, so scale doesn't affect them. Every distance-based model is affected.
05

Curse of dimensionality

As dimensions grow, every point is about equally far from every other, and the idea of a nearest neighbor loses its meaning.

  • This hits every distance-based model. K-means and RBF-kernel SVM suffer the same.
  • Each added dimension multiplies the number of points needed to cover the space.
06

Pros and cons

Every strength comes from having no training step. Every weakness comes from exactly the same place.

AspectGainCost
TrainingNone, just store the dataNo model to ship to production
PredictionUpdate the data and it's usable right awayScans the whole training set each time, unless indexed
MemoryNo parameters to storeKeeps the entire training set
BoundaryAny curve, no assumed shapeJagged when k is small, noise hits hard
Dimensions—In high dimensions distance loses meaning
Scale—Scaling is mandatory; get it wrong and results change
  • Choose KNN for a quick baseline, low-dimensional data, or similarity-based recommendation.
  • Choose trees or boosting for many dimensions, lots of data, or columns on different scales.
  • Worth learning not because it is used often, but because three concepts show most clearly here.
  • Those three concepts: high variance, the importance of scale, the curse of dimensionality.
  • Common mistakes: forgetting to scale, and trusting the training error of k = 1.
