Machine learning · Classical models

Linear regression

Draw a straight line through a cloud of points so the error is as small as possible. Three things to remember:

  • the model learns only two numbers: w and b
  • every decision lives in what "smallest error" means
  • change that definition and you get a different model
01

Mental model

Linear regression finds w and b so the line ŷ = w·x + b has the smallest total error.

  • Running example: 6 customers A–F, x is income (millions), y is extra spending.
  • Add a penalty on coefficient size and you get Ridge, Lasso and Elastic Net.
  • Wrap it in a sigmoid and measure with log loss and you get Logistic regression.
02

General formula

The loss is one number for each pair w, b. Find the pair that makes that number smallest.

ŷ = w1x1 + w2x2 + … + ba linear combination of the features
L = 1n Σ (ŷi − yi)2MSE: squared error, averaged
∂ L∂ wj = 2n Σ (ŷi − yi) · xijgradient: the error times that same feature
ŷ
the model's predicted value
y
the true value in the data
w, b
weight and intercept, what the model learns
n
number of samples
L
the loss; the smaller it is, the better the pair w, b
  • The gradient says which way to move w so the loss goes down. Its form is error times feature.
  • The same gradient form shows up in Logistic regression, with ŷ replaced by the probability p.
  • Changing the loss formula changes the model: section 04.
03

From table to line

Gradient descent adjusts w and b step by step, each step making the loss a little smaller.

  • The result w = 0.308, b = −6.46 matches the closed-form solution.
  • There is a formula that solves for the answer directly, the normal equation: w = (XTX)−1XTy.
  • It needs a matrix inverse, so it is slow with many features. Then use gradient descent.
04

MSE or MAE

MSE squares the error, so one outlier tilts the whole line. MAE takes the absolute value, so it is more robust.

  • Change customer E's y from +7 to +20: the MSE line's slope goes from 0.308 to 0.563, while the MAE line stays at 0.357.
  • Choosing the loss is choosing what to estimate: MSE gives the mean, MAE gives the median.
  • MSE has a closed form, which is why it became the default, not because it is more correct.
  • For long-tailed data use MAE or Huber loss, which caps large errors at a set level.
05

η and scaling

If the learning rate is too large, the loss goes up instead of down. If features are on different scales, no single η suits every column.

  • If η is too small, it heads the right way but so slowly it is useless.
  • Mismatched scales turn the loss surface into a long, narrow valley, so an η that suits one direction is too large for the other.
  • Gradient descent requires scaled features. The closed form is unaffected.
  • How to scale: Feature engineering.
06

Reading coefficients and multicollinearity

A coefficient can be read as a meaningful sentence, but when two columns say the same thing, the coefficients go wild.

With w = 0.308: 1M more income means 0.31M more spending, holding the other columns fixed. That sentence needs all three parts:

  • Units — without the units of x and y, a coefficient means nothing.
  • Holding the other columns fixed — and in practice that condition may be impossible.
  • Not causation — a coefficient only describes a relationship in the observed data.
  • Multicollinearity breaks reading individual coefficients, not prediction.
  • Measure it with VIF. Above 5 to 10 is a worry; here VIF reaches 5373.
  • If the goal is prediction, leave it or use L2. If the goal is explanation, drop or merge columns.
  • Coefficients of absurd size are a shared symptom of both multicollinearity and overfitting. The cure: Ridge, Lasso.
07

Four assumptions

These four assumptions are needed for statistical inference: p-values, confidence intervals, the claim "this variable has an effect".

AssumptionMeaningIf violated
LinearityThe x–y relationship is a straight lineSystematic underfit · residuals look curved
IndependenceResiduals are uncorrelatedStandard errors are underestimated · check how the data was collected
HomoscedasticityResiduals spread evenly at every prediction levelConfidence intervals are wrong · residuals look funnel-shaped
Normal residualsNeeded for hypothesis testsP-values unreliable · check with a Q-Q plot
  • If you only need prediction, evaluated on a separate test set, violations matter much less.
  • The first three assumptions can be seen in one plot of residuals versus predicted values.
  • Independence cannot be seen in a plot; you have to look at how the data was collected.
08

Pros and cons

Every strength comes from assuming the relationship is a straight line. Every weakness comes from exactly the same place.

AspectGainCost
InterpretabilityEach coefficient is a meaningful sentenceCorrelated columns scramble coefficients
TrainingClosed form, solved in one shotMatrix inversion is slow with many features
RelationshipFits even with little dataCurved relationships need hand-made higher-order features
OutliersMAE or Huber is more robustMSE is very sensitive; one point tilts the whole line
InferenceGives p-values and confidence intervalsNeeds the four assumptions in section 07
  • Choose linear regression when you need to read the relationship, or as a baseline before trying stronger models.
  • Choose Ridge or Lasso with many features or multicollinearity.
  • Choose gradient boosting when you only need accurate predictions on tabular data.
  • Common mistakes: forgetting to scale before gradient descent, and reading coefficients as causal effects.
