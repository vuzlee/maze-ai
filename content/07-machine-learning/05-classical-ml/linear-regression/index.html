Machine learning · Classical models

Linear regression

Draw the straight line that misses a cloud of points by the least. The model learns two numbers, w and b; every choice lives in what "misses by the least" means. Use it to read a relationship, or as the baseline before stronger models.

01

Mental model

Each row is a dot; linear regression finds the one line whose vertical gaps to the dots are smallest overall.

  • Running example: six customers A–F, x is income, y is extra spending.
  • Every result below comes from that one assumption: the relationship is a straight line.
02

General formula

The prediction is a weighted sum of the features; the loss is the average squared gap.

ŷprediction = w1x1 + … + wdxdone weight per feature + bintercept
MSEloss = 1n Σ (ŷi − yi)2average squared error over n rows
  • Squaring makes every gap positive and punishes big gaps far more than small ones.
  • Learning = finding the w, b with the smallest MSE: section 03.
03

How it learns

Two routes to the same line: solve it in one shot, or walk downhill step by step.

3.1Closed form

Set the gradient to zero and solve: with one feature it is two sums and a division.

w = Σ(xi − x̄)(yi − ȳ)Σ(xi − x̄)2how x and y move together, over how much x moves , b = ȳ − wx̄the line passes through the means
  • With many features the same idea is the normal equation w = (XTX)−1XTy.
  • Exact and one-shot, but the matrix inverse gets slow as the number of features grows.

3.2Gradient descent

Start anywhere, then move each weight against its gradient until the loss stops falling.

wjnew weight ← wjold weight − ηlearning rate · 2n Σ (ŷi − yi) xijgradient: error times that feature
  • After six steps w = 0.307: the same line as the closed form.
  • Scales to millions of rows and features; the same update trains Logistic regression and neural networks.
04

Key knobs

Three choices change the result: which loss, how big a step, and whether features share a scale.

4.1MSE or MAE

MSE squares the gap, so one far dot tilts the whole line; MAE takes the absolute gap and ignores it.

MAEloss = 1n Σ |ŷi − yi|average absolute error
  • MSE estimates the mean, MAE the median; MSE has a closed form, MAE needs an iterative solver.
  • Huber loss is the middle ground: squared for small gaps, absolute for large ones.

4.2Learning rate

Too large an η overshoots the bottom and the loss climbs instead of falling.

  • Too small an η heads the right way but takes forever.
  • Try a few values on a log scale (0.001, 0.01, 0.1) and watch the loss curve.

4.3Feature scaling

Features on different scales stretch the loss into a long thin valley that gradient descent zigzags across.

  • Standardize every column (mean 0, std 1) before gradient descent; the closed form does not care.
  • How to scale: Feature engineering.
05

Reading coefficients

A coefficient reads as a sentence — but when two columns say the same thing, they share the weight arbitrarily and the signs flip (multicollinearity).

  • w = 0.31 means one unit more income goes with 0.31 more spending — it needs the units, "other columns held fixed", and is a relationship in the data, not a cause.
  • It breaks reading coefficients, not predicting. Measure it with VIF (above 5–10 is a worry); absurdly large weights flag it and overfitting alike — fix by dropping or merging copies, or with Ridge, Lasso & Elastic Net.
06

Four assumptions

Linearity, independence, even spread and normal residuals are needed for p-values and confidence intervals; for prediction checked on a test set they matter much less. Plot residuals against ŷ to see the first ones.

6.1Linearity

If the truth bends, the residuals bend too: a U instead of a flat band.

  • The model underfits no matter how much data you add; add curved features such as x2 or use a tree model.

6.2Even spread

When errors grow with the prediction, the residuals fan out like a funnel (heteroscedasticity).

  • Predictions stay usable; confidence intervals and p-values do not.
  • The other two cannot be seen in this plot: independent rows (check how the data was collected) and normal residuals (Q-Q plot).
