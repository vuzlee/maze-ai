Machine learning · first lesson of the shelf

Machine learning overview

Machine learning is the branch of AI where a person supplies examples and the machine finds the rule: a gallery of the classic models and how they are measured, the taxonomy from label type to model family, and two AI winters on the way here.

01

What machine learning is

Machine learning is the branch of AI that learns its rules from data — and then checks them on data it has not seen.

  • Classic ML is the default for tables; raw pixels, words and sound go to Deep learning, the next shelf.
02

Rules learned from data

A hand-written rule cuts where a person guesses; a learned rule tilts until it fits the data.

  • Feature: an input column. Label: the column to predict. Loss: one number for how wrong the model is; learning pushes it down.
  • The price: you need enough labelled examples, and the rule is only as good as the data.
03

Taxonomy

One question splits the field: what kind of label does the data have — then the task picks the model family.

  • Labels and tasks: Supervised vs unsupervised. Under- and over-fitting: Bias–variance tradeoff.
  • Reinforcement learning sits outside the tree on this shelf; it is sketched below.

3.1Reinforcement learning

No labels, only a reward after actions; the agent learns how much each state is worth.

  • Examples: games, robot control, RLHF when tuning LLMs — see SFT & alignment.
  • Rare in day-to-day ML work, and no lesson on this shelf teaches it; supervised learning is most of it.
04

AI summers & winters

Interest in AI has boomed and crashed twice; each boom came from a new way to learn, each crash from promises it could not keep.

  • The curve is a sketch of interest and funding, not measured data.
  • Machine learning on tables grew steadily through the second winter; deep learning's story continues in the Deep learning overview.
05

Learning order

Eight stops. The first three are the base every model lesson assumes.

  • Start with Math foundations, then Statistics and Core concepts.
  • Then Classical models, Tree models, Clustering, PCA, Model evaluation.
