K-means clustering

K-means splits unlabelled points into k groups by repeating two steps: give every point to its nearest centroid, then move every centroid to the mean of its points.

01

Mental model

Place k centroids; assign each point to the nearest, move each centroid to its points' mean, repeat until nothing changes.

  • No labels: the clusters are whatever the two steps settle on, and k is chosen by you.
  • Every round lowers the same score, inertia, so the loop always stops — usually after a handful of rounds.
02

The loop

Two steps, each one lowers inertia while the other is held fixed.

2.1Assign step

Each point goes to the centroid with the smallest squared distance.

c(x)cluster of point x = argminj ‖x − μj‖2nearest centroid μj
  • A point can switch cluster when the centroids move: H goes from c2 to c1 in round 2.
  • Euclidean distance, so every column counts in its own units — see 5.3.

2.2Update step

Each centroid moves to the mean of the points assigned to it.

μjnew centroid = 1|Cj| Σx ∈ Cj xmean of its points
  • The mean is the point with the smallest sum of squared distances to the group — that is why this step lowers inertia.
  • Mini-batch k-means runs the same update on a small random batch per step: much faster on millions of rows, slightly worse inertia.

2.3Inertia

The score k-means minimises: squared distance of every point to its own centroid, summed.

WCSSinertia = Σj=1k Σx ∈ Cj ‖x − μj‖2within-cluster sum of squares
  • It can only go down, so the loop stops when an assign step changes nothing (inertia_ in scikit-learn).
  • It always falls as k grows, so it cannot choose k by itself — section 4.
03

Initialisation

The loop only goes downhill, so where it starts decides which minimum it ends in.

3.1Random init

k random points as centroids: two can land in one group, and the loop never repairs it.

  • A local minimum: every single assign or update step would raise inertia, yet a better split exists.
  • n_init runs the whole loop several times from different starts and keeps the lowest inertia.

3.2k-means++

Pick the first centroid at random, each next one with probability ∝ D², its squared distance to the nearest chosen centroid.

p(x)chance x is the next centroid = D(x)2Σx′ D(x′)2far points are likely
  • Spreads the starts over the groups, so the loop usually begins near the best split; it is scikit-learn's default init="k-means++".
  • Still random: keep n_init above 1 and fix random_state to reproduce a run.
04

Choosing k

Run k-means for several k and score each split; the score must not reward more clusters by itself.

4.1Elbow

Plot inertia against k; pick the bend where adding a cluster stops paying off.

  • Inertia keeps falling to 0 at k = n; only the change in slope matters.
  • On real data the bend is often soft — confirm it with the silhouette.

4.2Silhouette

For each point compare a, mean distance to its own cluster, with b, mean distance to the nearest other cluster.

s(x)from −1 to 1 = b − amax(a, b)1 = well inside, 0 = on a border, < 0 = wrong cluster
  • Pick the k with the highest mean s (silhouette_score); it does not grow with k.
  • Costs all pairwise distances, so on large data score a sample.
05

Hidden assumptions

K-means never raises an error: when its assumptions fail it still returns a confident wrong split.

5.1Round clusters

Inertia favours compact, round groups, so long or curved clusters get cut across.

  • Every boundary is a straight line halfway between two centroids; rings, moons and strips cannot be drawn with them.
  • For arbitrary shapes use DBSCAN; for stretched ellipses a Gaussian mixture.

5.2Equal sizes

The boundary sits halfway between centroids, whatever the cluster sizes, so a big cluster loses its edge.

  • Moving a few points from a wide cluster to a tight one lowers inertia, so the loop does it.

5.3Feature scale

Distance adds raw units, so the column with the largest numbers decides the clusters.

  • Put StandardScaler before KMeans in a pipeline, exactly as for KNN.
  • With many columns distances crowd together; reduce with PCA first.

5.4Outliers

Every point must join a cluster, and the mean follows a far point.

  • Remove outliers first, or use k-medoids (a real point as centre) or DBSCAN, which labels them noise.
