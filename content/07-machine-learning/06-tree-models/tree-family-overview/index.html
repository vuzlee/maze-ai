Machine learning · Tree models

Tree models overview

One tree is easy to read but fragile, so the whole branch is about combining many trees — in parallel (bagging) or in series (boosting).

01

One tree

The first idea: no formula, just yes/no questions on one column at a time.

  • Mixed columns, no scaling, thresholds and interactions for free — why trees rule tabular data.
  • How the questions are chosen: Decision tree.
02

High variance

A full-grown tree memorises its sample: drop a few rows and it draws different boxes.

  • Each tree is wrong in its own places — so many of them can cancel each other out.
  • Combining many weak models into one is called an ensemble.
03

Timeline

After 1996 every new name is a way to combine trees, not a new kind of tree.

  • Bagging stopped at one big name; boosting kept being refined.
  • XGBoost, LightGBM and CatBoost (2017) are gradient boosting made faster and regularised, not new algorithms; CatBoost's own twist is ordered boosting and native handling of categorical columns.
04

Ensembles

Two cures for two weaknesses: average deep trees or add up shallow ones.

4.1Bagging

Grow many deep trees on bootstrap samples, in parallel, and let them vote.

  • Two forests grown on the two samples of section 02 disagree on only 5.7% of test points, against 18.0% for two trees.
  • A random forest also lets each split see only a random subset of columns — Random forest.

4.2Boosting

Grow many shallow trees one after another, each fitted to what is still wrong, and add them up.

  • Re-weight the wrong rows: AdaBoost. Fit the remaining error directly: Gradient boosting.
  • Each step is scaled by a learning rate (0.3 for the 300 points; 1 in the six-row toy so the numbers stay readable), so no single tree decides much.
05

Comparison

Pick the lane by what the single tree lacks; inside boosting, pick the library by data size.

5.1Bagging vs boosting

More trees is always safe for a forest; boosting overshoots and needs early stopping.

Bagging · random forestBoosting · GBM, XGBoost, LightGBM, CatBoost
Base treedeep, fully grownshallow, 1–6 levels
Builtin parallel, independentin series, each on the leftover error
Curesvariancebias
Tuningdefaults are near-bestlearning rate, depth, early stopping
Noisy labelstolerates themlater trees chase them
  • Quick, robust baseline: random forest. Highest score with a good validation set: boosting.

5.2XGBoost vs LightGBM

Same gradient boosting objective; they differ in which leaf they split next.

  • Leaf-wise spends every split where the gain is biggest, so it reaches lower error with the same budget — but its deep branches can memorise small data, so cap num_leaves and min_data_in_leaf.
  • LightGBM also bins values into histograms and takes categorical columns directly: choose it for millions of rows or frequent retraining.
06

Learning order

Start with one tree; each lesson after it adds exactly one idea.

  • Decision tree → Random forest → AdaBoost → Gradient boosting → XGBoost · LightGBM.
  • Skip straight to XGBoost and you only learn which function to call.
