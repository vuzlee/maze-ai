Machine learning · Tree models

Gradient boosting

Gradient boosting adds shallow trees one after another, each one fitted to what the trees before it still get wrong, and adds only a fraction η of each.

01

Mental model

Start from one guess; every round a small tree learns the residual and moves the prediction part of the way toward the truth.

  • The same six customers as the Decision tree; every tree here is a single split (a stump), η = 0.5.
  • Trees are added, not averaged: the prediction is the start value plus η × every tree.
  • Random forest grows deep trees in parallel; boosting grows shallow ones in sequence.
02

Residual as gradient

The residual is the negative gradient of the loss, so each tree is one step of gradient descent on the predictions.

Fm(x)prediction after m trees = Fm−1(x)what the earlier trees say + η · hm(x)new tree, scaled by the learning rate
ripseudo-residual of row i = − ∂ L(yi, F)∂ Fdownhill direction of the loss
  • Pick a loss L; it decides the start value, the residual and the leaf value. Everything else is the same loop.
  • The tree is always a regression tree on r, even when the task is classification.
03

Regression

Squared loss ½(y − F)²: the residual is the plain error, and a leaf returns its mean.

3.1Residual

Start every row at the mean of y; the residual is what that guess misses.

F0start value = ȳmean of y , ri = yi − F(xi)error of row i
  • The mean is the single number with the lowest squared loss, so it is the best tree with zero splits.

3.2Tree on the residual

Grow a small regression tree with r as the label; each leaf returns the mean residual.

γjvalue of leaf j = Σi ∈ j rinjmean residual in the leaf
  • The split search is exactly the variance scan of the Decision tree, run on r instead of y.
  • Trees are kept shallow: max_depth 3 to 6 in practice, one split here.

3.3Update

Add η × the leaf value to every row, recompute the residual, fit the next tree.

Fm(x)prediction after m trees = Fm−1(x)what the earlier trees say + η · hm(x)new tree, scaled by the learning rate
  • The next tree sees the new residual column: r1 replaces r0, the table and the loop stay the same.

3.4Prediction

A new row walks every tree; its prediction is F0 plus η × each leaf it lands in.

  • The trees never vote: their scaled leaf values are summed, so a later tree can pull the answer back down (tree 3 here).
04

Classification

Log loss: F is the log-odds, the residual is label − probability, and a leaf divides by the curvature.

4.1Residual

Start every row at the log-odds of the base rate; the residual is y − p.

pprobability of buy = σ(F)sigmoid of the log-odds , ri = yi − pinegative gradient of log loss
  • The trees add up in log-odds, which can be any number; only at the end does σ turn it into a probability — as in Logistic regression.

4.2Tree on the residual

The same regression tree on r; the leaf value is one Newton step.

γjvalue of leaf j = Σi ∈ j riΣi ∈ j pi(1 − pi)gradient over curvature
  • A residual of 0.5 means little in log-odds; dividing by p(1 − p) converts it into the right log-odds step.
  • With squared loss the curvature is 1 per row, so the same formula gives the mean of 3.2.

4.3Update

Add η × the leaf value to the log-odds, map back with σ, recompute the residual.

Fm(x)prediction after m trees = Fm−1(x)what the earlier trees say + η · hm(x)new tree, scaled by the learning rate
  • More than two classes: one tree per class per round, one log-odds per class, softmax at the end.

4.4Prediction

The same walk, summed in log-odds; σ turns the sum into a probability.

  • predict_proba returns σ(F); predict says buy when it is at least 0.5.
05

Learning rate & stopping

The two knobs that matter most: how big each step is and how many steps to take.

5.1Learning rate

A smaller η takes smaller steps, so it needs more trees for the same fit.

  • learning_rate and n_estimators trade off: halve one, roughly double the other.
  • Small steps generalise better, because no single tree can push the model far: the usual recipe is η 0.05–0.1 and many trees.

5.2Early stopping

Keep adding trees while a validation error still falls; stop when it turns up.

  • Training error always keeps falling, so it cannot tell you when to stop — see Train, validation & test.
  • Set n_estimators high as a ceiling and let n_iter_no_change (or early_stopping_rounds) pick the number.

5.3Subsampling

Fit each tree on a random fraction of the rows: stochastic gradient boosting.

  • subsample 0.5–0.8 is typical; below 1 it also gives an out-of-bag error estimate for free.
  • Shallow trees are the other brake: max_depth 3 is the usual default, because each tree only needs to fix part of the error.
