Machine learning · Tree models

Gradient boosting

Many shallow trees in sequence, each learning the residual of the trees before it. Three things to remember:

  • each later tree learns the residual, which is the negative gradient of the loss
  • changing the loss only changes how the residual is computed
  • the final prediction adds up the trees with η, it does not average
01

Mental model

Gradient boosting is many shallow trees in sequence: each tree learns the residual the earlier trees still get wrong, then is added in with η.

  • There is one formula: each tree learns the negative gradient of the loss. Regression and classification just plug their loss into it.
  • Random forest grows trees in parallel and averages. Here they are grown in sequence and added up.
  • Running example throughout: 6 customers A–F, y is the extra spending (in thousands). Classification uses the buy-or-not label.
  • The easiest boosting to picture: AdaBoost. The version with regularization: XGBoost.
02

General formula

Each round adds one tree that learns the negative gradient of the loss with respect to the prediction. The loss only enters at the residual step.

Order of computation, from table to new prediction:

  • With MSE, the residual is y − F. So "learning the residual" is really gradient descent, with each step being a tree.
  • Unlike ordinary gradient descent: it updates the prediction function directly, not any parameters.
  • The loss only needs to be differentiable, so there is a gradient to follow.
03

Regression and classification

Plug a loss into the formula from section 02. Changing the loss changes how the residual and leaf values are computed.

Lossresidual rleaf value
Regression: MSE ½(y − F)²y − Fmean of r in the leaf
Classification: log lossy − pΣ r / Σ p(1 − p)
  • With MSE the denominator is the row count, so the leaf value is just the mean residual.
  • Classification: F is the log-odds. The prediction is p = logistic(F), and it is F that accumulates, not p.
  • A noise-tolerant loss like Huber clips the residual at ±δ, so one broken label skews the model less.
  • XGBoost uses this same formula and adds λ and γ.
04

From table to one tree

The tree learns the residual. It tries every column and every threshold, and picks the split that reduces squared error the most.

  • Each tree has leaves like a random forest, but a leaf holds a correction value, not a label or a mean of y.
  • Error drop = SSE of the root − SSE of the two leaves. This is the idea behind Gain in XGBoost when λ = 0.
  • The figure stops at one level for brevity. In practice max_depth is usually 3 to 6.
05

Adding up many trees

Each later tree learns the residual of the one before. The final prediction adds up the trees, rather than averaging or voting.

Random forestGradient boosting
What each tree learnsa bootstrap sample of ythe residual of earlier trees
Combiningaverage or voteadd, each tree times η
Trainsong songsequential
Treesgrown deepshallow
  • Averaging cannot fix shallow trees that err in the same direction. Adding up fixes the residual piece by piece.
  • Deep trees memorize from the first few rounds. Noise once added in cannot be removed by later trees.
  • A tree of d levels captures interactions among at most d columns.
06

η, number of trees and stopping

A small η needs more trees. The standard recipe: small η, a very large number of trees, stop with early stopping.

  • Measured on this lesson's 6-row table, one-level trees. From η = 0.3 down, η × number of trees barely changes.
  • n_estimators is only a ceiling. A tree once added cannot be removed, so adding trees forever means learning noise.
  • Early stopping: stop when the error on the validation set turns back up. See Train, validation and test.
  • Changing one of η and the number of trees while keeping the other fixed unintentionally changes the model's strength.
07

Pros and cons

It trades interpretability and speed for accuracy. Every strength and weakness comes from adding up shallow trees one at a time.

AspectGainLose
AccuracyTop of the class on tabular dataMust tune η, tree count, depth
LossChanging the loss changes the problem: regression, classification, rankingThe loss must be differentiable
Input dataNo scale standardization needed, captures interactions by itselfCategorical variables usually have to be encoded first
OverfittingHas early stoppingAdding trees forever means memorizing
Label noiseHuber tolerates noise better than MSELater trees pour effort into rows that are wrong, broken labels included
Training and reading the modelShallow trees are easy to implementSequential, so slow. Hundreds of trees added together cannot be read rule by rule
  • Choose gradient boosting for tabular data when you need the highest accuracy. Practical versions: XGBoost, LightGBM.
  • Choose random forest when labels are noisy or you need a quick baseline with little tuning.
  • Choose AdaBoost to learn the principle of boosting. See AdaBoost.
