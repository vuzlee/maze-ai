Machine learning · Tree models

XGBoost

XGBoost is gradient boosting whose every tree is grown by one scored formula: residuals summed per node decide the splits and the leaf values, with γ and λ keeping both small.

01

Mental model

Each round fits one tree to the residuals, but a formula picks its splits and its leaf values.

  • The same six customers as Decision tree; here the target is spend.
  • Residuals, the small step η and adding trees up are Gradient boosting; this lesson is only how XGBoost grows one tree.
02

Objective

Loss plus a price per leaf and a price on leaf size; each leaf's part is a parabola with a known bottom.

Objwhat each tree minimises = Σi l(yi, ŷi)loss of every row + γTprice per leaf + ½ λ Σj wj2price on leaf size
Objloss as a parabola per leaf ≈ Σj [ Gjwj + ½ (Hj + λ) wj2 ]G, H = Σ g, Σ h in leaf j + γTprice per leaf
wj*bottom of the parabola = − GjHj + λOutput value
  • g, h are the slope and curvature of the loss at each row; the loss enters only through them.
  • Squared error gives g = −r, h = 1; log loss gives g = −r, h = p(1 − p). H is called Cover.
03

Regression

Squared error: residual spend − ŷ, every row adds 1 to Cover.

3.1Similarity

How well one value fits a node: large when residuals agree in sign, 0 when they cancel.

Similarityscore of one node = (Σi ri)2n + λr = residual · denominator = Cover + λ
  • It is the depth of the parabola's bottom, times 2: section 02.

3.2Gain & split

Try every column × every threshold; keep the split whose children gain the most Similarity.

Gainwhat the split earns = SimLleft child + SimRright child − Simnodebefore the split
  • The same greedy scan as Decision tree; only the score changes.
  • The root has Similarity 0 because the start value 25 is the mean: the residuals sum to 0.

3.3Output value

A leaf returns its residual sum over Cover + λ: the mean, pulled toward 0.

Outputvalue the leaf returns = Σi rin + λthe w* of section 02
  • The tree adds η × w to the prediction; the next tree learns what is left.
04

Classification

Log loss: residual y − p, every row adds p(1 − p) to Cover; leaves speak log-odds.

4.1Similarity

Same score, new Cover: large when residuals agree in sign, 0 when they cancel.

Similarityscore of one node = (Σi ri)2Σi pi(1 − pi) + λr = residual · denominator = Cover + λ
  • Every prediction starts at p = 0.5, so residuals are ±0.5 and each row adds 0.25 to Cover.

4.2Gain & split

The same Gain formula and the same scan as 3.2, on the new Similarity.

  • Same winner as regression here, age 31.5 — the residual column decides, and both happen to split there.
  • This split needs min_child_weight=0: under the default 1, leaf A B (Cover 0.5) is too light — section 7.3.

4.3Output value

A leaf returns residual sum over Cover + λ, in log-odds; σ turns it back into a probability.

Outputvalue the leaf returns = Σi riΣi pi(1 − pi) + λthe w* of section 02
  • This is one Newton step on the log loss, not a mean: the λ = 0 value −2 lies outside the residuals.
05

Prediction

A new row walks every tree to one leaf; the prediction is the start plus η × the sum of those leaf values.

  • η (learning_rate, default 0.3) is the shrinkage of Gradient boosting: each tree moves the prediction only part of the way.
  • Each tree is grown to at most max_depth (default 6) levels.
06

Missing values

Every split learns a default direction: rows with a missing value go to whichever side gives the larger Gain.

  • Called the sparsity-aware split: no imputation needed, and zeros in a sparse matrix can be treated the same way.
  • At prediction time a row missing that column follows the stored default arrow.
07

Reining it in

The penalties sit inside the score, so the tree stops itself when a split is not worth its price.

7.1γ — pruning

Every leaf costs γ: a split whose Gain is below γ is cut, bottom up.

  • gamma (alias min_split_loss), default 0. The library drops the ½, so Gain is compared with γ directly.
  • The tree is grown to max_depth first, then pruned bottom up.

7.2λ — shrinking

λ sits in every denominator: leaf values and gains shrink, most in small nodes.

  • reg_lambda, default 1; reg_alpha adds an L1 price that can set a leaf to exactly 0.
  • With λ = 1 the regression tree here stops at depth 1 on its own, even with γ = 0.

7.3min_child_weight

A child must carry Cover ≥ min_child_weight; otherwise the split is not allowed.

  • In classification Cover shrinks as p nears 0 or 1, so confident nodes stop splitting; section 04 assumes min_child_weight=0.
  • Further brakes are Gradient boosting's: small η, early stopping, and random subsets — subsample (rows per tree) and colsample_bytree (columns per tree), both default 1.
