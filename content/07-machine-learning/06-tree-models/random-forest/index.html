Machine learning · Tree models

Random forest

A random forest grows many decision trees, each on its own random sample of rows and columns, and lets them vote.

01

Mental model

One tree is unstable; many different trees, each trained on its own random bag of rows, vote it away.

  • The same six customers as Decision tree; there a tie made one tree answer no and another buy for X.
  • Two sources of randomness make the trees differ: the bag of rows (section 02) and the columns each split may see (section 03).
02

Bootstrap

Each tree gets n rows drawn with replacement from the n training rows: some repeat, some are left out.

P(row left out)never drawn in n draws = (1 − 1n)nmiss it every time → 1e ≈ 0.37for large n
  • The rows a tree never saw are its out-of-bag rows, about a third of the table — section 06 uses them.
  • Bootstrap + averaging is bagging (bootstrap aggregating); bootstrap=True is the default.
03

Random features

At every split, a tree may only choose among a random few columns, so one strong column cannot win every root.

  • The draw is redone at every node: the left child of tree 1 draws again and splits on age.
  • max_features sets how many: "sqrt" (√p) is the classifier default; the regressor uses all p unless told otherwise.
  • With every column allowed it is plain bagging; the column draw is what makes it a random forest.
04

Aggregating

A new row walks every tree; the forest combines their answers into one.

4.1Classification: vote

Each tree answers with its leaf's class; the majority wins.

  • sklearn averages the trees' predict_proba (soft vote) and takes the top class; with pure leaves that is the same as counting votes.

4.2Regression: mean

Each tree answers with its leaf's number; the forest returns the mean.

  • The same bags, but each tree is a regression tree on spend; the mean of several staircases is a smoother staircase.
  • Still no extrapolation: every tree repeats its last step, so their mean does too.
05

Why it works

Averaging B trees shrinks variance, but only down to how alike the trees are.

Var(forest)B trees, each of variance σ² = ρ σ2floor: ρ = correlation of two trees + (1 − ρ) σ2Bvanishes as B grows
  • Bootstrap and random features lower ρ; trees are grown deep (low bias, high σ2) because averaging only removes variance, not bias.
  • On the 300 noisy points from Decision tree: one full tree 21.0% test error, 100 bagged trees 15.0%, a random forest of 100 trees 13.7%.
  • More trees never overfit; past a few hundred they only cost time (n_estimators, default 100).
06

OOB score

Score each row with only the trees that never saw it: a free validation set.

  • oob_score=True, then read oob_score_; with enough trees it lands close to cross-validation at no extra training.
  • It assumes rows are independent: on time series a bag mixes past and future, and the score is too kind.
07

Feature importance

Two ways to ask which column matters: what its splits removed, or what is lost without it.

7.1MDI

Mean decrease in impurity: the tree importance of each tree, averaged over the forest.

  • Free with training; read it from feature_importances_.
  • Measured on the training bags, so it rewards columns with many distinct values, even pure noise.

7.2Permutation

Shuffle one column on held-out rows; the drop in accuracy is its importance.

  • sklearn.inspection.permutation_importance; shuffle a few times and average.
  • Two correlated columns share the credit: shuffle one, the other still carries the signal, and both look weak.
08

Hyperparameters

Four knobs matter; the defaults are usually close to the best.

  • n_estimators: more trees never hurt accuracy, only time (section 05).
  • max_features: fewer columns per split, less alike trees (lower ρ) but weaker ones.
  • max_depth, min_samples_leaf: trees are grown deep by default; raise min_samples_leaf to smooth noisy leaves and shrink the model.
  • Extra Trees (ExtraTreesClassifier) also draws each split's threshold at random instead of searching it: faster, trees even less alike.
