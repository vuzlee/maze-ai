Machine learning · Tree models

Decision tree

In goes a data table, out comes a tree of questions. Three things to remember:

  • how a data table becomes a tree
  • how one node splits
  • why a tree memorizes, and how to rein it in
01

Mental model

A tree only knows how to ask one kind of question: x < threshold ? — and then repeat it.

  • Computing impurity and splitting in two are two jobs of the same node.
  • The dashed arrow goes back — that is recursion.
  • Recursion does not stop on its own: that is why there are hyperparameters.
  • The building block of Random forest, Gradient boosting, XGBoost, LightGBM.
02

Data in

Each row is a sample, each column a feature, the last column is the label.

  • The whole table goes into the root node.
  • Pick a column and a threshold, split the table in two.
  • Each half is a node again — repeat step 2.
  • When it stops, that node becomes a leaf node, carrying the majority label of the remaining half-table.
  • Going from root to leaf, collecting the split conditions along the way — that is how a tree produces a prediction.
  • The longest path is the depth. The larger the depth, the more easily the tree memorizes.
  • A leaf returns the class proportions inside it, not logits — a tree has no continuous computation at all.
03

Impurity metrics

The machine needs one number measuring impurity, to compare which of two splits is better.

Three measures

Gini — the formula

Gini — a worked example

Which measure to choose

Gini vs Entropy

They measure the same thing and almost always give the same tree. Entropy penalizes mixed nodes slightly more, so the tree is sometimes more balanced.

What to choose

Gini — because it is cheaper, no logarithm to compute. Only switch to entropy once you have run out of hyperparameter tuning.

04

Classification

The label is a class. The whole tree is just the node-splitting step repeated.

  • Step 2 scores every column × every threshold, not just the age column.
  • It always takes the highest gain right now — greedy, never looking more than one step ahead.
  • Unless forbidden, it repeats until one sample per leaf — the tree memorizes the old data.
  • All three questions in STEP 5 land on the age column: a column that never wins on gain never enters the tree — feature selection is something the tree does by itself.
05

Regression

The same four steps. Change the measure and what a leaf returns, and you are done.

Consequence: the graph is a staircase

  • Predictions take only a finite set of values: as many numbers as there are leaves — so the graph is a staircase, not a curve.
06

Stop criteria and pruning

Two ways to rein it in: forbid further splits during training, or cut some off after training.

Pre-pruning · stop criteriaPost-pruning
WhenForbid splitting during trainingGrow fully, then cut back from the leaves up
Parametersmax_depth · min_samples_leaf · min_impurity_decreaseccp_alpha — the larger, the harder it cuts
Basis for cuttingPreset thresholds: too deep, too few samples in a leaf, gain too lowMerge a branch into a leaf, keep it if the validation score does not get worse
  • The default is no reining in — the tree grows to one sample per leaf; you must set at least the depth yourself.
  • Pre-pruning is fast so it is usually tried first; post-pruning is more accurate because it sees the whole tree.
  • The stronger cure is in the next lesson: do not rein in one tree, grow many trees.
07

Loss function

A tree does not follow the gradient of a smooth function. What it minimizes is error on train plus a penalty for each leaf.

Rα(T)total cost of a tree = R(T)error rate on train + α · |T|penalty per leaf
T
the tree under consideration, |T| is its number of leaves
R(T)
the share of training data the tree gets wrong
α
the price paid per leaf — set via ccp_alpha
  • At α = 0 the tree grows to 62 leaves, 0% error on train but 19.3% on test — a formula that penalizes nothing reins in nothing.
  • The gain at each node jumps in steps with the threshold, not continuously — so a tree tries everything; there is no derivative to follow.
08

Pros and cons

Every strength of a tree comes from comparing within one column at a time. Every weakness comes from exactly the same place.

AspectProsCons
PreparationNo scaling needed—
Reading the modelPrint the tree and it becomes if-else rules—
Column typesNumeric and categorical share one tree—
Prediction range—No extrapolation: train on prices of 1–5 billion and it only ever predicts within 1–5 billion
Stability—Change a few rows and the whole tree is completely different
Accuracy—One tree usually loses to a forest of trees
Defaults—max_depth defaults to unlimited — leave it unset and the tree splits to one sample per leaf
  • Choose a single tree when you need to explain every prediction: application review, processes with a human checker.
  • Instability sounds like bad news, but it is exactly what makes Random forest work.
  • Choose max_depth and ccp_alpha by cross-validation, not by eyeballing a picture of the tree.
  • For more accuracy, move on to Random forest or XGBoost.
