Linear algebra

Data is a matrix, a model is a transformation. Three things to remember:

  • the dot product measures how much two arrows agree
  • a matrix moves the whole space; its columns say where the axes land
  • an eigenvector is a direction that is only stretched — the root of PCA
01

Mental model

One row of data is one arrow; the whole table is one matrix.

  • A 28×28 image is one arrow in 784-D; a word embedding is one arrow in a few hundred dimensions.
  • Shapes are written rows × columns: X is n × d, samples × features.
02

Vectors

Three numbers describe a pair of arrows: length, dot product and cosine.

2.1Length (norm)

The length of an arrow is Pythagoras applied to its components.

‖a‖ = √(a21 + a22 + … + a2n)square each component, add, take the root
‖a‖1 = |a1| + |a2| + … + |an|L1: add the absolute values (city-block distance)
  • The first line is the L2 norm, the second the L1 norm (Lasso penalty); Euclidean distance between two points is the norm of their difference.
  • The same norm reappears as the L2 penalty in Ridge and weight decay.

2.2Dot product

Multiply pair by pair and add: one number for how far one arrow goes along the other.

a · b = a1b1 + a2b2 + … + anbnmultiply each pair, then add up
  • A linear model predicts with exactly one dot product: ŷ = w · x + b.
  • Large-valued features dominate the sum — scale features before linear models, KNN and SVM.

2.3Cosine similarity

Divide the dot product by both lengths and only the angle is left.

cos θ = a · b‖a‖ ‖b‖dot product with both lengths divided out
  • Two texts of very different length can still score 1 if they point the same way.
  • Semantic search, recommenders and RAG retrieval rank candidates by cosine to the query vector.
03

Matrix multiplication

Matrix multiplication is many dot products at once, and it moves the whole space.

3.1Row times column

Each cell of the result is one row of the left matrix dotted with one column of the right.

Cij = Σk Aik Bkjrow i of A · column j of B
  • Order matters: AB ≠ BA, and BA may not even exist.
  • Matrix form exists to run fast: GPUs parallelize it, Python loops do not.

3.2Shapes

Read the shapes before the contents: the inner sizes must match and then disappear.

  • Every dense layer and every attention projection reads as (n × d) · (d × k) → (n × k).
  • Writing the shape next to each multiplication catches mismatches before the code runs.

3.3Matrix as a transformation

A matrix moves every point of space; its columns are where the two axis arrows land.

  • A neural network layer is such a move followed by a non-linear bend (the activation).

3.4Linear layer

A dense layer is one matrix multiplication plus a shift: each row of W turns the whole input into one output.

y(k × 1) output = W(k × d) weights x(d × 1) input + b(k × 1) bias
  • Stack layers with an activation in between and you have an MLP; without the activation they collapse into one matrix.
  • Parameter count is k·d + k: a 784 → 256 layer has about 200k weights.

3.5Transpose & inverse

Transpose swaps rows and columns; the inverse is the matrix that undoes a move.

(AT)ij = Ajirow i becomes column i
AA−1 = Iidentity: the move that changes nothing
  • Transpose appears everywhere shapes need to line up: XTX, QKT in attention.
  • In practice you solve Ax = b directly instead of computing A−1; it is faster and more stable.
04

Rank

Rank is the number of truly independent columns — the dimensions that survive the transformation.

4.1Lost dimensions

When one column copies another, the matrix flattens space and the lost dimension cannot come back.

  • A rank-deficient matrix cannot be inverted: two duplicate features leave linear regression without a unique solution.
  • Ridge fixes this by adding a little to the diagonal.

4.2Low-rank factorization

A big matrix with low rank can be stored as two thin matrices multiplied together.

Wd × d ≈ Bd × r · Ar × d, with r ≪ d
  • Real data is almost always low-rank — columns are tangled — which is what makes compression and dimensionality reduction work.
  • LoRA fine-tunes an LLM by learning only such a low-rank update.
05

Eigenvectors

A few directions are only stretched, never turned — they describe a matrix better than its numbers.

5.1Eigenvalue & eigenvector

Apply the matrix to every direction: the ones that keep their line are eigenvectors.

A vapply the matrix = λ vsame direction, length × λ
  • Only square matrices have eigenvectors; rectangular ones use SVD — the same idea, and how PCA is computed in practice.

5.2PCA

The eigenvectors of the covariance matrix are the directions in which the data spreads most.

C = XTXn − 1covariance of centred X (each column minus its mean), d × d
variance kept = λ1 + … + λkλ1 + … + λdeigenvalues kept over all eigenvalues
  • A direction where the data barely varies cannot tell points apart, so dropping it costs little.
  • Scale features first, or the column with the largest units takes over PC1. Full lesson: PCA.
