Probability

The language for talking about the unknown, and where the loss function is born. Four stops:

  • a distribution is a table of how often each value occurs
  • expectation is the center, variance is the spread around it
  • Bayes is how to flip a condition — and it needs the base rate
  • MLE and MAP derive the loss function, rather than picking it on a whim
01

Random variables and distributions

A random variable is a quantity whose value is not yet known; a distribution is a table of what percentage each value gets.

  • Discrete means countable values, described by a PMF; continuous means spread over an axis, described by a PDF.
  • A PDF is not a probability: its value can exceed 1, only area is probability.
  • A classification model outputs a distribution over classes; the label only appears at the threshold step.
02

Conditional probability and independence

P(A | B) reads as the probability of A given that B happened — new information changes belief.

  • The mechanism is changing the denominator: look only within the group satisfying B, not the whole set.
  • Independence means P(A | B) = P(A) — and only then may you multiply two probabilities.
  • Multiplying blindly without independence gives a number that shrinks very fast and is surely fake.
  • Naive Bayes deliberately assumes independence while knowing it is false — in return it is very fast.
03

Common distributions

Each distribution is a story of how the data is generated. Recognize the story and you know which distribution to pick.

  • Normal shows up everywhere because averages of many summed things always tend toward it — the reason is the CLT just below.
  • But real data is often right-skewed: income, latency, session time — take the log first.
  • Pick the wrong distribution and the loss function is wrong too, because loss comes from a distributional assumption.
04

Expectation

Expectation is the center of mass of a distribution, not the most common value. And it is always linear.

  • E[X+Y] = E[X]+E[Y] holds even when X, Y are dependent — this is where it differs from variance.
  • Every loss function is an expectation — E[(y−ŷ)²], E[−log p].
  • On real data, replace the expectation with the sample mean.
05

Variance and standard deviation

Variance measures the mean squared distance from the expectation — and unlike expectation, it is not linear.

  • Var[X+Y] = Var[X]+Var[Y] only when independent; in general add +2·Cov[X,Y].
  • Standard error shrinks with √n: twice the precision needs four times the data.
  • That is the formula behind Random Forest — averaging many trees cuts variance, bias stays the same.
  • Trees in a forest are not fully independent, so Cov is the part that is lost.
06

Covariance and correlation

Correlation is covariance normalized to the range −1 to 1 — easy to read, but it only catches linear relationships.

  • r near ±1 signals two redundant features; near 0 does not mean unrelated.
  • Highly correlated features make linear regression coefficients meaningless.
  • The costliest form: a feature correlated with the label through data leakage — great in testing, broken in production.
07

Law of large numbers and CLT

Two theorems tell the same story from two angles: the sample mean converges to the true expectation, and it does so in a bell shape.

  • The law of large numbers guarantees you can measure it; the CLT tells how wrong you are — the basis of every confidence interval.
  • The CLT applies to the sample mean, not the raw data: income stays right-skewed.
  • It needs independent samples — time series or many rows per user give falsely narrow confidence intervals.
  • The bridge to Statistics — confidence intervals and hypothesis tests are all built on the CLT.
08

Flipping the condition

Bayes exists to answer the question people actually ask: having observed this result, how likely is the hypothesis to be true?

  • P(A|B) and P(B|A) are two different numbers — in this example they differ 50-fold.
  • The culprit is the base rate: 5% of a huge group still outweighs 99% of a tiny one.
  • Mass screening always needs a second test.
09

Parts of the formula

The formula adds nothing to the count we just did — it only names each part so we can talk about it concisely.

  • prior → times likelihood → normalize by evidence → gives the posterior.
  • The denominator only normalizes, so when comparing two hypotheses it cancels — a trick used all over ML.
  • Today's posterior is tomorrow's prior — with new data, keep updating.
10

Bayes trong machine learning

The base-rate trap is not just a medical thing — it sits inside every imbalanced dataset.

  • high recall but low precision on fraud data does not mean the model is bad.
  • Naive Bayes multiplies per-feature likelihoods assuming independence.
  • In MAP, the log of the prior is exactly the regularization penalty term.
  • The prior carries the conclusion when data is scarce and is overwhelmed when data is plentiful — exactly how regularization works.
11

Where loss functions come from

MSE and log loss are not conventions — they can be derived from an assumption about the data.

  • Flip the question: don't ask "how wrong is the model", ask "which parameters make this data most likely".
  • Using MSE asserts that errors are symmetric around 0 with no heavy tails — a real assumption.
12

Maximum likelihood

MLE picks the parameters that maximize the probability of generating exactly this dataset.

  • Take the log before optimizing because a product of thousands of numbers below 1 underflows to 0; log is monotonic so the maximum does not move.
  • The key: the negated log-likelihood is a loss function — the rest is just plugging in a distribution.
13

MSE and log loss

Plug two different distributions into the same formula and you get the two most familiar loss functions.

  • Normal error → MSE; Bernoulli labels → log loss.
  • For heavy-tailed errors, the Laplace assumption gives MAE, estimating the median instead of the mean.
  • Pick the loss by the nature of the data: use MSE with outliers and a few points drag the whole line.
14

MAP and the prior

MLE listens only to the data. MAP also listens to a prior belief about the parameters — and that belief, once you take the log, turns out to be exactly the regularization term.

  • Normal prior → L2 / Ridge; Laplace prior → L1 / Lasso; no prior → back to MLE.
  • Lasso pushes coefficients to exactly 0 because the Laplace prior is peaked at 0 — the shape of the prior, not an implementation trick.
  • The more data, the more the likelihood overwhelms the prior — the same mechanism seen with Bayes above.
  • So regularization rescues small datasets and is nearly harmless on large ones.
15

Common mistakes

The four mistakes below all lead to the opposite conclusion, and the first three vanish just by naming the reference group.

  • Flipping the condition is harmless only when P(A) = P(B) — almost never.
  • Quick check: rewrite the question as "within which group, what percentage?"
