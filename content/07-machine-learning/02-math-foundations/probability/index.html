Probability

The language for the unknown, and where the loss function comes from. Four stops:

  • a distribution says how likely each value is
  • expectation is the center, variance the spread
  • Bayes flips a condition and needs the base rate
  • MLE and MAP derive the loss function instead of picking it
01

Describing the unknown

A random variable is a number not known yet; a few summaries describe it: center, spread, link to others.

1.1Random variable and distribution

A distribution gives each value its probability: bars for countable values, area under a curve for a continuum.

P(X = x) = p(x)PMF: a bar per value , Σx p(x) = 1bars add up to 1
P(a ≤ X ≤ b) = ∫ba f(x) dxPDF: area between a and b , ∫ f(x) dx = 1total area is 1
  • Discrete values use a PMF (probability mass function); continuous ones a PDF (probability density function).
  • A PDF height can exceed 1; only area is a probability.

1.2Cumulative distribution function

The CDF answers "how likely is a value at most x": add the bars, or the area, from the left up to x.

F(x) = P(X ≤ x) = Σt ≤ x p(t)discrete: a staircase or ∫x−∞ f(t) dtcontinuous: an S-curve
F′(x) = f(x)the density is the slope of the CDF
  • F never goes down, starts at 0 and ends at 1; P(a < X ≤ b) = F(b) − F(a).
  • Percentiles and the median read straight off it: the median is where F = 0.5.

1.3Expectation

Expectation is the balance point: each value weighted by its probability.

E[X] = Σx xeach value · P(x)times its probability
E[X] = ∫ x f(x) dxcontinuous: the sum becomes an integral
E[aX + b] = a E[X] + blinearity: shift and scale pass through
  • It is linear: E[X + Y] = E[X] + E[Y], even when X and Y are dependent.
  • On real data the sample mean stands in for it. Every loss is an expectation of an error.

1.4Variance

Variance is the average squared distance from the mean; its square root, the standard deviation, is in the data's own units.

Var[X] = E[(X − μ)2]mean squared distance from the center , σ = √Var[X]standard deviation
Var[X] = E[X2] − E[X]2shortcut for computing it
Var[aX + b] = a2 Var[X]a shift does nothing, a scale counts squared
  • Not linear: Var[X + Y] adds 2 Cov[X, Y] unless they are independent.
  • The mean of n independent draws has spread σ / √n — why Random Forest averages trees.

1.5Covariance and correlation

Covariance says whether two variables move together; correlation rescales it to −1 … 1.

r = Cov[X, Y]σX σYcovariance, scaled to −1 … 1 , Cov[X, Y] = E[(X − μX)(Y − μY)]do they deviate together?
  • r near 0 does not mean unrelated: it only sees straight lines.
  • Strongly correlated features make linear regression weights unstable.
02

Common distributions

Five shapes cover most data: one coin, a count of coins, a count of rare events, flat, and the bell. Counts get bars (PMF), measurements get curves (PDF).

2.1Bernoulli

One trial, yes or no.

P(X = 1) = p,  P(X = 0) = 1 − p
E[X] = pmean·Var(X) = p(1 − p)largest at p = 0.5
  • Binary labels are Bernoulli; its negative log-likelihood is the log loss in 5.2.

2.2Binomial

Count the yeses in n independent trials.

P(X = k)=C(n, k)ways to pick kpk (1 − p)n−kone such sequence
E[X] = npmean·Var(X) = np(1 − p)variance
  • A sum of n Bernoullis; for large n it looks Gaussian (CLT, 4.2).

2.3Poisson

Count of rare events in a fixed window.

P(X = k)=λk e−λk!λ = average count per window
E[X] = Var(X) = λmean equals variance
  • The binomial with many tries and a tiny p; if the variance is much bigger than the mean, the data is overdispersed.

2.4Uniform

Every value in [a, b] is equally likely.

f(x)=1b − aflat height, area 1 for a ≤ x ≤ b
E[X] = a + b2midpoint·Var(X) = (b − a)212variance
  • Probability is width × height — the simplest picture of "area is probability".

2.5Gaussian

The bell: sums of many small effects end up here.

f(x) = 1σ√2πkeeps the area at 1 exp(−(x − μ)22σ2)μ = center, σ = width
E[X] = μ,  Var(X) = σ2mean, variance
z = x − μσhow many σ from the mean
  • 68–95–99.7: about 68%, 95% and 99.7% of a Gaussian lies within 1, 2 and 3 σ of μ, so |z| > 3 is rare.
  • Measurement noise, linear-regression errors and weight initialisation all assume it.
03

Conditioning and Bayes

New information shrinks the world you count in; Bayes turns P(B | A) into P(A | B).

3.1Conditional probability

P(A | B) counts A only inside the group where B is true.

P(A | B) = P(A ∩ B)P(B)both, out of the new, smaller world
P(A ∩ B) = P(A) P(B)independent: knowing B changes nothing about A
  • Independent means P(A | B) = P(A); only then P(A ∩ B) = P(A) P(B).
  • Naive Bayes assumes independence on purpose to stay fast.

3.2Bayes' rule

An accurate test can still give mostly false alarms when the condition is rare.

P(A | B)posterior = P(B | A) · P(A)P(B)likelihood × prior ÷ evidence
P(B)evidence = P(B | A) P(A)positives among the sick + P(B | ¬A) P(¬A)positives among the well
  • The base rate P(A) decides: 5% of a huge group outweighs 99% of a tiny one.
  • Same trap in ML: on imbalanced data (fraud) high recall can come with low precision.
  • Today's posterior is tomorrow's prior.
04

Law of large numbers and CLT

The sample mean converges to the expectation, and its error is bell-shaped.

4.1Law of large numbers

Average enough independent draws and you hit the expectation.

  • This is why a sample mean or an average loss on data is a fair stand-in for E[X].
  • It needs independent draws; many rows from one user count as fewer samples.

4.2Central limit theorem

Whatever the source looks like, the mean of many draws follows a Normal bell.

X̄n ≈ Normal(μ,centred on the true mean σ2n)spread shrinks with n
  • It is about the mean, not the raw data: income stays skewed.
  • Confidence intervals and tests in Statistics are built on it.
05

From probability to loss

Assume how the data was generated, ask which parameters make it most likely — the loss falls out.

5.1Maximum likelihood

MLE (maximum likelihood estimation) picks the parameter under which the observed data is most probable.

θ̂ = argmaxθbest parameter Σi log P(xi | θ)log-likelihood: product became a sum
  • Take the log: a product of thousands of numbers below 1 underflows to 0, and log keeps the maximum in place.
  • Minimizing the negative log-likelihood is the same thing — that is a loss function.

5.2MSE and log loss

Plug a Normal error into the negative log-likelihood and get MSE; plug a Bernoulli label and get log loss.

MSE = 1n Σ (yi − ŷi)2Normal error
log loss = −1n Σ [yi log pi + (1 − yi) log(1 − pi)]Bernoulli label
P(y | p) = py (1 − p)1 − yBernoulli likelihood of one label ⇒ −log P = −[y log p + (1 − y) log(1 − p)]its negative log is log loss
  • Normal → linear regression; Bernoulli → logistic regression; Laplace → MAE.
  • MSE assumes symmetric errors with thin tails; outliers drag it.

5.3MAP and the prior

MAP (maximum a posteriori) adds a prior belief about the weights; its log is the regularization term.

θ̂MAP = argmaxθ log P(D | θ)fit the data (MLE) + log P(θ)prior → −λ‖w‖² or −λ‖w‖₁
  • Normal prior → L2 / Ridge; Laplace prior → L1 / Lasso, see Ridge, Lasso & Elastic Net.
  • More data, the likelihood wins: regularization matters most on small data.
