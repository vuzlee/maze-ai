Statistics

Draw conclusions about the whole population from a sample, and do it on a live system. Four things to remember:

  • a p-value is not the probability the hypothesis is true
  • power decides how many samples you need — compute it before, not after
  • looking at results repeatedly (peeking) inflates the false-alarm rate
  • statistical significance is not practical significance
01

Testing

Assume nothing changed, then ask whether the data is too rare to believe.

1.1P-value

The p-value is the share of the “nothing changed” curve that lies at or beyond what you observed.

z = x̄B − x̄ASEgap in standard errors
p = P(|Z| ≥ |z| | H0)area beyond the observed gap, both tails
  • It is P(data | H0), not P(H0 | data) — turning one into the other needs Bayes and a base rate.
  • A large p means failed to reject, not “no difference”.
  • It says nothing about size: with enough data a 0.01% gap still gives p < 0.05.

1.2Type I and type II errors

One cut splits two worlds: the cut decides how often you cry wolf and how often you miss a wolf.

  • Type I = false positive, rate α; type II = false negative, rate β.
  • Moving the cut right trades fewer false alarms for more misses.
  • Convention: α = 0.05, power 1 − β = 0.80.

1.3Power and sample size

More samples shrink the noise, so a real effect sits further from zero and is easier to catch.

n ≈ 2 (z1−α/2 + z1−β)2 σ2MDE2per group: 1.96 and 0.84 for α = 0.05, power 0.80
  • Fix α, power and the minimum detectable effect (MDE); the sample size follows.
  • Halve the MDE and you need four times the sample.
  • Compute it before the test; if the answer is months, the test is not worth running.

1.4Confidence interval

A 95% interval comes from a method that covers the true value in 95% of repeated samples.

CI = x̄sample mean ± 1.9695% of a normal · σ√nstandard error
  • The true value is fixed; the interval is what moves from sample to sample.
  • Its width shrinks with √n: four times the data, half the width.
  • Report the effect with its interval — a p-value only says “different from 0”.

1.5Multiple comparisons

Test enough metrics and one will look significant by luck alone.

P(≥ 1 false win) = 1 − (1 − α)mm independent tests
αeach = αmBonferroni correction
  • 20 metrics at α = 0.05 give a 64% chance of at least one false win.
  • Bonferroni tests each at α / m — simple, conservative; Holm is a strictly better variant, BH controls the false discovery rate.
  • Cheapest fix: fix one primary metric before the test starts.
02

Correlation vs causation

Two things moving together does not mean one causes the other.

2.1Confounder

A hidden third variable can drive both, and the link vanishes once you hold it fixed.

  • Other look-alikes: reverse causation (B causes A), selection bias, survivorship bias.
  • All of them produce the same correlation as a true cause.
  • Correlation r measures only a linear link, from −1 to 1.

2.2Randomization

A coin decides who gets the change, so every hidden trait splits evenly between the groups.

  • Randomization balances even variables you never measured — no other method can.
  • When you cannot randomize: difference-in-differences, instrumental variables, regression discontinuity — each adds assumptions you cannot test.
03

A/B testing

A randomized experiment on live users: split, wait, decide.

3.1Experiment design

Hash each user into a group, fix the primary metric and the sample size before the first visitor.

  • Split by user, not by visit; include the experiment id in the hash so groups reshuffle per experiment.
  • One primary metric; the rest are guardrails that only must not get worse.
  • Run at least one full week — weekend behaviour differs.

3.2Peeking

Stopping the first time p dips under 0.05 turns noise into wins.

  • Early on the gap swings widely, so it almost always crosses the line at some point.
  • Fix the sample size and look once — or use a method built for looking: sequential testing or Bayesian A/B.

3.3Statistical vs practical significance

Small p answers “is it different”; only the interval against a threshold answers “is it worth it”.

  • Big samples make tiny effects significant.
  • Set the ship threshold before seeing the result.
