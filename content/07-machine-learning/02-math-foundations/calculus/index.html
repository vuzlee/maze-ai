Calculus

All of training is walking downhill. Three things to remember:

  • a derivative is a slope; the gradient collects every slope into one arrow pointing uphill
  • the chain rule multiplies slopes backward through a pipeline — that is backpropagation
  • gradient descent steps against the gradient; on a convex loss it always finds the one bottom
01

Derivatives

A derivative answers one question: nudge the input a little — how much does the output move?

1.1Derivative = slope

Join two points on the curve, slide them together, and the line's slope becomes the derivative.

f ′(x) = limh→0 f(x + h) − f(x)hrise over run, with the run shrinking to zero
  • Positive slope: increasing the input raises the output. Zero slope: a flat spot — a bottom, a top or a saddle.
  • Nobody derives these by hand in ML: autograd in PyTorch and JAX computes them.

1.2Gradient

With many parameters, take one slope per parameter; together they form an arrow that points uphill.

∇L = ( ∂L∂w1 , … , ∂L∂wn )one partial slope per parameter
  • A partial slope ∂L/∂w1 moves one parameter and holds the rest still.
  • The gradient's length carries information: long on a steep wall, near zero at the bottom.

1.3Common derivatives

Four slopes cover most of ML; the sigmoid one reuses the value already computed.

(xn)′= n xn−1power rule
(ex)′= exits own slope
(log x)′= 1xbehind log-loss gradients
σ′(x)= σ(x) (1 − σ(x))sigmoid: reuses its own output
  • Chain these with the chain rule below and you can differentiate any layer by hand.
  • σ′ never exceeds 0.25, so a deep stack of sigmoids shrinks the gradient at every layer.
02

Chain rule

A model is a pipeline of functions, so its slope is the product of each stage's slope.

2.1Pipeline

Values flow forward through the boxes; slopes flow backward and multiply.

dydx = dyduslope of the outer box · dudxslope of the inner box
  • Backpropagation is this rule applied to a computation graph, one box per operation.
  • Each backward step reuses the value saved in the forward pass — that is why training stores activations.

2.2Vanishing & exploding gradients

Multiply many slopes and the product drifts to zero or to infinity.

  • Vanishing: early layers stop learning. Exploding: the loss jumps to NaN.
  • Gradient clipping caps the exploding case; the fixes for both live in the deep-learning shelf.
03

Gradient descent

Repeat one move: compute the gradient, step against it.

3.1Update rule

The ball moves against the slope, by the learning rate times the slope.

wnew weight ← wold weight − ηlearning rate · ∇L(w)gradient: points uphill
  • Mini-batch SGD computes the gradient on a small batch: a noisier direction but many more steps per second.
  • Gradient boosting borrows this idea: each new tree fits the remaining gradient.

3.2Learning rate

The same curve and the same start — only η changes.

  • Too large: the loss bounces or diverges. Too small: training crawls.
  • In practice η is tuned first and often decays during training; Adam adapts it per parameter.
04

Convex functions

A convex function has exactly one bottom — every downhill walk ends there.

f″(x)≥ 0curve bends upward everywhere
f(tx + (1−t)y)curve between x and y ≤ t f(x) + (1−t) f(y)chord between them, 0 ≤ t ≤ 1
  • Convex: every stopping point is the global optimum. Non-convex: the result depends on the start.
  • This is the real boundary between classical models and deep learning.
