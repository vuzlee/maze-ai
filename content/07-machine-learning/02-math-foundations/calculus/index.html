Calculus

All of training is walking downhill. Three things to remember:

  • the gradient is the direction of steepest ascent — going against it lowers the loss
  • the chain rule is how the gradient flows backward through many layers
  • for a convex function every local minimum is the global minimum
01

Gradient

A derivative is a slope: nudge a parameter up a little and how much does the loss change. Collecting every partial slope into one vector gives the gradient.

  • The only property to remember: the gradient points where the loss rises fastest — so go the opposite way.
  • The gradient's length carries information: shrinking means near the bottom, very long means on a steep wall.
  • Nobody writes derivatives by hand — autograd takes care of that.
02

Chain rule

A model is a function nested in a function, so the derivative of the whole chain is the product of each stage's derivative.

  • Backpropagation is not a new algorithm — it is the chain rule applied to a computation graph.
  • Multiplying many stages grows errors exponentially: vanishing when the factor is < 1, exploding when > 1.
  • Non-saturating activations, weight initialization, normalization, skip connections — all exist to keep that product near 1.
03

Gradient descent

Repeat one move: compute the gradient, step against it, repeat.

  • η too large and the loss bounces or turns NaN; too small and it never reaches the bottom.
  • Mini-batches give a noisier direction but many more steps — the noise sometimes even helps escape shallow dips.
  • Gradient boosting borrows exactly this idea: each new tree learns the remaining gradient.
04

Convex functions

A convex function has exactly one bottom — however you walk downhill, you end up at the same place.

  • Convex means every stopping point is the global optimum; non-convex means the result depends on the starting point.
  • This is the real boundary between classical models and deep learning.
  • In high dimensions most zero-gradient points are saddles, which can be escaped — so neural networks still train well.
