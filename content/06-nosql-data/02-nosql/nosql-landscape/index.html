Database · beyond SQL

NoSQL — four families

When to leave the relational database. Three things to remember:

  • four families: key-value · document · wide-column · graph
  • dropping a fixed schema means moving it into code, not getting rid of it
  • NoSQL is designed around queries, not around data
01

Mental model

NoSQL is four families — pick the one shaped like your most common question.

  • All four trade away JOIN, multi-table transactions or a fixed schema for scale or shape.
  • The default is still relational — switch for a concrete reason.
02

NoSQL families

Each family stores data in a different shape, and that shape decides which queries are fast.

2.1Key-value

A key is hashed to a bucket — one jump to the value.

  • Redis, DynamoDB: caches, sessions, counters.
  • No query by value — only by the exact key.

2.2Document

Each record is a JSON document; queries look inside it.

  • MongoDB, Couchbase: products, profiles — records with their own fields.

2.3Wide-column

Rows hold many columns sorted by a key; writes append, reads take a slice.

  • Cassandra, HBase: logs, time-series metrics, heavy writes.
  • The row key must match the query — design it first.

2.4Graph

Data is nodes and edges; a query walks from node to node.

  • Neo4j, Neptune: social networks, recommendations, fraud rings.
03

Where the schema goes

Dropping a fixed schema moves it into your code; it does not remove it.

3.1Schema-on-write

The database rejects a bad row at write time.

  • Relational databases work this way.

3.2Schema-on-read

The database accepts anything; every reader must cope.

  • PostgreSQL JSONB and MongoDB JSON Schema blur the line.
04

Query-driven design

List the queries first, then build one table per query.

  • With no JOIN, data is duplicated on purpose.
  • Copies can briefly disagree — eventual consistency.
  • Splitting data across machines: replication & sharding.
05

Polyglot persistence

Put NoSQL next to the relational database, each store doing one job.

  • Only one place is written directly; the rest can be rebuilt.
  • Add a store when you measure a bottleneck.
