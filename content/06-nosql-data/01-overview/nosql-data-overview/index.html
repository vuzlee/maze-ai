NoSQL & data systems — overview

Read this first: where data goes after the SQL database, which lesson fits which problem, and the order to read them.

01

Mental model

The SQL database handles small exact writes; data that will not fit a table, and questions that scan everything, go elsewhere.

  • NoSQL = not the relational model (key-value, document, column-family, graph) — the app must keep the data correct.
  • Analytics runs on a separate warehouse, fed by a pipeline, so it never slows the live app.
  • Read this shelf after the SQL shelf: you need to know what you give up.
