NoSQL & data systems — overview

When one SQL database is no longer enough, data goes to stores built for one shape of data, and through a pipeline to analytics.

01

What this shelf is

Beside the SQL database sit stores built for one shape of data, and systems that move data to analytics.

  • Continues SQL & relational: NoSQL = not the relational model, so the app must keep the data correct.
  • Vector databases belong to RAG: they are taught on the LLM shelf.
02

One real data system

Live data and analytics live in different stores, joined by a pipeline.

  • The live side answers one user in milliseconds; the analytics side scans everything and never slows the app.
  • Most apps stay on one SQL database plus a cache for years — leave only for a named limit.
