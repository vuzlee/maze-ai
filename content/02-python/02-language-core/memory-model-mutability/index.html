Memory model & mutability

In Python, a name and an object are two different things.

  • a name is a tag on an object; = never copies
  • each line either moves a tag or changes an object
  • mutability decides whether the object can change
01

Mental model

Names live on the stack, objects on the heap; every arrow is an address.

  • b = a copies the address: two names, one object.
  • List slots hold addresses too, so a one-level copy still shares the items.
02

Names and objects

A name only points; the object holds the data.

2.1Everything is an object

Even 5 is an object on the heap.

sys.getsizeof(5) is 28 bytes; it has an id and methods.

2.2Assignment adds a name

b = a copies the address, not the data.

id(a) == id(b) is True; del a removes only the tag.

03

Rebind or mutate

Ask of every line: does it touch the name or the object?

3.1Rebind a name

b = … moves only b.

3.2Mutate the object

b[0] = 9 changes the object; every name sees it.

b += [9] mutates a list, but rebinds a tuple, int or str.

3.3A function mutates its argument

The parameter is a new name for the same object.

Python passes arguments by assignment — neither by value nor by reference.

3.4A function rebinds its parameter

Rebinding changes only the name inside the function.

Convention: return a new object (sorted) or mutate and return None (list.sort).

04

Mutable vs immutable

Mutability decides whether change in place is allowed.

4.1Mutable

list, dict, set change in place; the id stays.

4.2Immutable

int, str, tuple never change; a new object is built.

  • Immutability is shallow: (1, [2, 3]) still lets you append to the inner list.

4.3Building a string in a loop

Collect the pieces, then join them once.

s = "".join(parts)

05

Copying

Assignment never copies; a copy is independent only as deep as it goes.

5.1Assignment

b = a: no copy at all.

5.2Shallow copy

A new outer list, shared items.

a[:], list(a), a.copy() and copy.copy(a) are all shallow.

5.3Deep copy

copy.deepcopy(a) copies every level.

Flat data only needs a shallow copy; deep copy is much slower.

06

is and ==

== compares content; is compares identity.

  • Write x is None, not x == None.
  • Small ints (−5 to 256) are cached, so is can look right on numbers — never rely on it.
07

Common mistakes

All come from one fact: assignment shares, it does not copy.

7.1Mutable default argument

The default list is created once, when def runs.

Fix: def add(x, out=None): then out = [] if out is None else out.

7.2Repeating a nested list

[[0]*3]*3 repeats one row three times.

Fix: [[0]*3 for _ in range(3)].

7.3Removing while iterating

Items shift left while the index moves on, so items get skipped.

Fix: build a new list, or loop over a copy: for x in a[:]:.
