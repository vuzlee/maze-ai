02

List cấp phát thế nào

Hết chỗ thì xin vùng lớn hơn khoảng 1,125 lần rồi chép sang. Chia đều, mỗi append vẫn O(1).

  • Biết trước kích thước thì cấp phát sẵn [None] * n — bỏ hẳn các lần chép.
  • list.copy() và a[:] là shallow copy: chép lớp ngoài, phần tử bên trong vẫn dùng chung.

03

Vì sao tuple hashable

Hash phải không đổi suốt đời object. Sửa được thì không đảm bảo được điều đó.

tuple — làm khoá được

Bất biến → hash tính một lần là xong.

d[(2, 3)] = "ô" — khoá toạ độ, rất hay dùng cho bài lưới.

list — không

Sửa được → hash sẽ đổi → object nằm sai ô, tra không thấy.

Python chặn thẳng: TypeError: unhashable type.

tuple chứa list thì cũng hết hashablehash((1, [2])) → lỗi

04

Set và frozenset

Set là hash table bỏ phần giá trị. Cùng cơ chế với dict, cùng chi phí.

a & b     # giao — O(min(len(a), len(b)))
a | b     # hợp
a - b     # hiệu
a ^ b     # đối xứng: có ở đúng một bên

frozenset({1, 2})     # bản bất biến → làm khoá dict được
  • Đổi x in list thành x in set là O(n) → O(1) — cách tối ưu rẻ nhất trong Python.
  • Set không giữ thứ tự; cần cả hai thì dùng dict.fromkeys() để lọc trùng mà vẫn giữ thứ tự chèn.
  • Bốn phép toán tập hợp thay được cả vòng lặp — code ngắn hơn và chạy trong C.
05

Lỗi hay gặp

Bẫy đầu tiên là nguyên nhân số một khiến lời giải đúng bị timeout.

in trên list là O(n)

Trong vòng lặp thì thành O(n²). Đổi sang set là xong — nhớ kiểm tra chỗ này đầu tiên khi code chậm.

[[0]*m]*n

Tạo n tham chiếu tới cùng một hàng. Sửa một ô là cả cột đổi theo. Dùng list comprehension.

Dựa vào thứ tự của set

dict giữ thứ tự chèn từ Python 3.7, set thì không. Đừng viết code phụ thuộc thứ tự lặp của set.

06

Hỏi đáp phỏng vấn

Tự trả lời thành tiếng trước, rồi mới mở ra.

Vì sao tuple làm khoá dict được mà list thì không?

Khoá phải có hash không đổi suốt đời. Tuple bất biến nên đảm bảo được; list sửa được nên Python chặn thẳng.

x in list và x in set khác nhau thế nào?

List phải quét tuần tự — O(n). Set tính hash ra thẳng ô — O(1) trung bình. Đây là chỗ tối ưu rẻ nhất.

List cấp phát bộ nhớ ra sao?

Hết chỗ thì xin vùng lớn hơn rồi chép sang, nên append là O(1) amortized — một lần lẻ có thể O(n).

Lọc trùng mà vẫn giữ thứ tự, làm sao?

list(dict.fromkeys(a)). Set lọc trùng nhanh nhưng không giữ thứ tự.
