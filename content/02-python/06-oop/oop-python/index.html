OOP in Python

Four pillars, with three Python twists.

  • encapsulation is a naming convention, not a lock
  • polymorphism needs no common base class
  • super() follows the MRO, not "the parent"
01

Encapsulation

From outside a class there are three outcomes: OK, allowed but impolite, and a real error.

  • _x is a convention only — Python still returns the value.
  • __x is renamed to _Account__pin (name mangling): hidden, not locked.
  • Intent: _x for subclasses too, __x for the declaring class only.
02

Abstraction

Show what an object can do, hide how. ABC forces subclasses to fill in the shown part.

  • Encapsulation hides data; abstraction hides complexity.
  • A missing @abstractmethod raises TypeError when the object is created, not when it is called.
  • Lighter option without inheritance: Protocol.
03

Inheritance & MRO

Two paths from D to A: C3 linearization turns the tree into one line, so A runs once.

D.__mro__ → (D, B, C, A, object)

  • super() means the next class in the MRO — inside B it calls C.
  • An inconsistent base order makes Python refuse to create the class.
  • Prefer composition over deep inheritance.
04

Polymorphism

One name, many behaviours. Python has duck typing and overriding, but no overloading.

4.1Duck typing

Any object with the right method fits — no shared base class needed.

To write down "needs a speak()" without inheritance, use Protocol.

4.2Method overriding

A subclass redefines a method; the first match in the MRO wins.

Run the parent's version too with super().greet().

4.3Method overloading

A second def with the same name replaces the first.

Instead use default arguments, *args, or functools.singledispatch.

05

Class vs instance attributes

Assigned in the class body: shared by every object. Assigned in __init__: one per object.

def __init__(self): self.items = []

  • Same trap as a mutable default argument.
06

__slots__

__slots__ drops the per-object __dict__: about 7× less memory per object.

class P: __slots__ = ("x", "y")

  • Measured with sys.getsizeof on CPython 3.12, two attributes.
  • Cost: no new attributes at runtime, and trickier inheritance.
