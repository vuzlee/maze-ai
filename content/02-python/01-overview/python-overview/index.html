Python overview

A handful of consistent rules; learn them and the rest follows.

  • everything is an object; a name is a tag on it
  • interpreted, dynamically typed, garbage-collected
  • three groups to read in order, three to read when needed

Mental model

02

What Python is

Three properties you will meet in every lesson.

2.1Interpreted

Source becomes bytecode, which the CPython VM runs.

CPython is the standard implementation — the python3 you run. Slower than compiled code, but no build step.

2.2Dynamically typed

The type belongs to the object, and is checked at run time.

Type hints document intent; Python does not enforce them — see Type hints & dataclass.

2.3Garbage-collected

An object no name points to is freed automatically.

Details: Memory management & GC.
