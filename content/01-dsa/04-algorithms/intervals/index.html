Interval

Sort the bars, then each one only meets its neighbour.

01

Mental model

An interval is a bar on a number line. Sorted, overlaps can only happen between neighbours.

1.1Sorting the bars

After sorting by start, compare each bar with the previous one only.

1.2Cost

Every pair is O(n²); sort + neighbours is O(n log n).
