Algorithms — the map

After reading a problem, two questions need an answer right away: which pattern does it belong to, and which approaches does this data size allow.

01

Mental model

The eleven lessons in this group fall into just four pattern families. The words in the problem tell you which family to think of.

  • Pick the wrong family and you lose the whole session — each lesson has its own section on recognizing problems, in more detail than here.
  • Each family name in the right column is its own recognition section in its lesson — here there is only enough to recognize it, not to solve it.
02

Choosing an algorithm

A problem always tells you how large the data is. That number rules out most directions before you even start thinking.

GivenAllowed up toCommon approach
n ≤ 20O(2n)backtracking, bitmask DP
n ≤ 500O(n³)2D DP, Floyd-Warshall
n ≤ 5,000O(n²)DP over two strings, exhaustive search with pruning
n ≤ 10⁵O(n log n)sorting, binary search, heap, graph
n ≤ 10⁷O(n)two pointers, sliding window, prefix sum
n ≥ 10⁹O(log n)binary search on the answer, a formula

how to read this table in detail: Big-Othe problem gives n up to 10⁵ and you came up with an O(n²) approach — you are not on the right track yet
