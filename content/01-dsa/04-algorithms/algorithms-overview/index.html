Choosing an algorithm

The data size rules out most speeds before you start thinking.

2.1Data size to speed

About 10⁸ simple operations fit in one second; pick the slowest speed under that line.

GivenAllowed up toCommon approach
n ≤ 20O(2n)backtracking, bitmask DP
n ≤ 500O(n³)3D DP, Floyd-Warshall
n ≤ 5,000O(n²)DP over two strings
n ≤ 10⁵O(n log n)sorting, binary search, heap, graph
n ≤ 10⁷O(n)two pointers, sliding window, prefix sum
n ≥ 10⁹O(log n)binary search on the answer, a formula

details: Big-On up to 10⁵ and your idea is O(n²)? not there yet
