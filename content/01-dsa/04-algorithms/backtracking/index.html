Backtracking

Walk a tree of choices: choose, go deeper, undo — and cut branches that cannot work.

01

Mental model

Every enumeration problem is a decision tree; backtracking walks it depth-first with one shared path.

1.1Choose, explore, unchoose

Append going down, pop coming back up — the path is shared by every branch.

1.2Pruning

Ask "can this still work?" before going deeper — a cut branch costs nothing.

1.3Tree size

Unpruned, the tree has 2ⁿ subsets or n! orders — only small n survives.
