Dynamic
programming

Answer each small question once, write it in a table, and build the big answer from it.

01

Mental model

DP invents no new work — it stops doing the same work twice.

1.1Overlapping subproblems

Plain recursion asks the same question again and again; a memo answers it once.

1.2Filling the table

Say what dp[i] means, fill the base cells, then each cell reads cells already filled.

1.3Cost

Time = number of cells × work per cell.
