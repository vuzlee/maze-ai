01

Mental model

A big problem repeats the same subproblem many times. Compute it once, then recall it — DP invents no new computation; it only removes the duplicated work.

  • It only applies when the problem has overlapping subproblems — the same arguments asked again many times, exactly the red part of the figure.
  • The tree in the figure is the top-down version (recursion + memoization). The bottom-up version fills the same cells in reverse order and gives the same result — write the recursive one first, it is easier to think about.
  • The number of blue cells is the number of states, and that is also the complexity: DP costs about the number of cells times the work per cell.

03

Common mistakes

The first trap is the real reason people find DP hard.

A state missing information

If you can't say what dp[i] means in one sentence, the state is wrong. You usually need another dimension: dp[i][used].

Wrong loop order

The cell being computed must draw from cells already finished. 0/1 knapsack iterates backward, unbounded iterates forward — they differ in exactly this spot.

Index mix-ups with a padded table

With a (n+1)×(m+1) table, dp[i][j] corresponds to characters a[i-1], b[j-1].

Pattern 2 — knapsack

Signals: "choose some items so the total equals / does not exceed" · making change

The loop order decides the problem: if each item is used once, iterate capacity backward; if it may be reused, iterate forward.

for item in items:
    for c in range(C, item-1, -1):      # BACKWARD → each item once
        dp[c] = max(dp[c], dp[c-item] + value)

Pattern 3 — two strings

Signals: two strings/arrays · "most similar" · "fewest edits"

A (n+1)×(m+1) table. Compare a[i-1] with b[j-1]: if equal take the diagonal, otherwise take the min or max of the neighbors.

Pattern 5 — subsequences & intervals

Signals: "longest increasing subsequence" · palindromes · "in which order to burst the balloons"

LIS: dp[i] = length of the longest increasing subsequence ending at i — O(n²), or O(n log n) with binary search.
Interval DP: iterate by increasing interval length, not by index.
