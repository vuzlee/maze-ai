Two pointers

Each step rules out one possibility for good and never revisits it. Read for 2 minutes, then go down to the patterns to practice.

01

Mental model

Each step rules out one end from every remaining possibility — rule out n times and you're done, hence O(n). The whole technique stands or falls on one question: looking at one pair, can you deduce which end to drop?

  • Nested loops are O(n²) because they revisit pairs already known to be bad. Two pointers rules out a whole batch in one step — the "ruled out" column sums to exactly the number of pairs.
  • The drop rule must be provably safe: a pair ruled out cannot beat the pair being kept. If you can't prove it, go back to a hash map — Hash map.
  • The fast & slow template is the same idea on a different axis: one pointer reads, one writes, and neither moves back — section 06.
02

Code templates to memorize

The converging ends template for sorted arrays. The fast & slow template for modifying an array in place.

# TEMPLATE A — converging ends: a SORTED array
L, R = 0, len(a) - 1
while L < R:
    s = a[L] + a[R]
    if   s == target: return L, R
    elif s <  target: L += 1      # need larger → drop the smallest
    else:             R -= 1      # need smaller → drop the largest
# TEMPLATE B — fast & slow: overwrite in place, O(1) memory
slow = 0                          # next write position
for fast in range(len(a)):        # position being read
    if keep(a[fast]):
        a[slow] = a[fast]; slow += 1
return slow                       # length of the kept part

03

Common mistakes

All three fail silently — the code still runs and still gives a plausible-looking answer.

Forgetting to sort

Template A is only right when the array is sorted — it relies on "dropping the left end can only raise the sum". On an unsorted array that reasoning collapses.

Not skipping duplicates in 3Sum

After finding a triple you must skip past every equal value at both ends, or the answers repeat.

Mixing up L < R and L <= R

If you need two different elements, use <. Using <= adds an element to itself.

05

Pattern 1 — converging ends

Signals: a SORTED array · "two numbers that sum to" · palindromes · largest area

  • Use template A, changing only the comparison that decides which end to drop.
  • 3Sum: fix one number, then run template A on the rest — O(n²), not O(n³).
