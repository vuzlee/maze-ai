DSA · algorithms

Graph — BFS, DFS, topo sort

One loop, one box of waiting vertices.

01

Mental model

Pop a vertex, push its unseen neighbours — the box decides the order.

1.1BFS — a queue

Take from the front: the search spreads in rings, so the first hit has the fewest edges.

1.2DFS — a stack

Take from the back: the search dives down one branch before trying the next.

1.3O(V + E)

Each vertex is popped once, each edge checked once from each end.
