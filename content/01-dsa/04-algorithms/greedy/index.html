DSA · algorithms

Greedy

Take the best option now and never look back — right only when you can show it is safe.

01

Mental model

One choice per step, never undone. Cheap when it works, silently wrong when it does not.

1.1Take the best now

Each step takes the biggest coin that still fits, then moves on.

1.2When greedy fails

Same rule, other coins: the run looks fine but misses the best answer.

1.3Why a greedy choice is safe

Swap the greedy pick into a best answer — if it stays just as good, greedy is right.

02

Patterns

Most greedy problems are sort by the right key, then one pass.

2.1Smallest that fits

Sort both sides and give each need the smallest thing that satisfies it.

Signals: match two lists · "maximum number of people served" · each item used once
