DSA · data structures

Linked list

Nodes joined by arrows: relinking is cheap, reaching a node is not.

01

Mental model

No row of cells — each node points at the next.

1.1Nodes and arrows

A node holds a value and an arrow to the next node; head is the way in.

02

Properties

Changing links is O(1); getting to the right node is O(n).

2.1Insert at head

Two arrows change — O(1) for any length.

2.2Find a node

No index jump: follow the arrows one by one — O(n).

2.3Delete a node

Re-point one arrow past it — O(1) once you hold the node before it.

2.4Reverse

Three pointers, one arrow flipped per step — O(n), O(1) memory.
