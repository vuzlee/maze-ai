Mental model

A tree that is only half sorted, stored in a plain array.

1.1A tree stored in an array

Children of i sit at 2i+1 and 2i+2 — no pointers needed.

1.2The heap rule

Every parent is ≤ its children, so the minimum is at the root.

02

Properties

Python's heapq is a min-heap; for a max-heap, push negated values.

2.1Peek

h[0] is the minimum — O(1).

2.2Push

heappush: append at the end, then swap upward — O(log n).

2.3Pop

heappop: the last value fills the root, then swaps downward — O(log n).

2.4Search

Any value other than the minimum needs a full scan — O(n).

2.5Why O(log n)

A swap moves one level, and a tree of n values has only log₂ n levels.
