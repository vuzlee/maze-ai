DSA · data structures

Union-Find
(DSU)

"Are these two in the same group?" — answered almost instantly while groups keep merging.

01

Mental model

Each group is a tree; same root means same group.

1.1Groups as trees

Every element points at a parent; the root points at itself.

02

Properties

Two operations, find and union; their cost is the height of the tree.

2.1Find

Climb the arrows until a node points at itself.

2.2Union

Find both roots, hang one under the other.

2.3Path compression

After a find, every node passed points straight at the root.

2.4Union by size

The small tree goes under the big one, so trees stay short.

2.5Cost

With both tricks, almost O(1) per operation.

03
