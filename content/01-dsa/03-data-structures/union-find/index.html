DSA · 2 minutes + practice

Union-Find
(DSU)

Answers "are these two elements in the same group" almost instantly, even while groups keep merging. Read for 2 minutes, then go down to the patterns.

01

Mental model

Each group is a tree, and you only need to know the root. Same root means same group — but the taller the tree, the more each question costs, so the two optimizations that keep trees short are the real substance of this structure.

  • Two operations: find(x) returns the root, union(a,b) joins two roots.
  • Path compression cures: every node climbed past is pulled straight to the root. Union by size prevents: the small tree always hangs under the big one.
  • With both, every operation is nearly O(1). Missing one, the code still gives the right answer — just slower, so this bug never reveals itself.
02

Code template to memorize

Eight lines. Both optimizations are required: path compression and union by size.

p = list(range(n)); sz = [1] * n

def find(x):
    while p[x] != x:
        p[x] = p[p[x]]              # path compression: skip one level
        x = p[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra == rb: return False          # already same group → this edge makes a cycle
    if sz[ra] < sz[rb]: ra, rb = rb, ra  # merge the small tree into the big one
    p[rb] = ra; sz[ra] += sz[rb]
    return True

union returning Falseis exactly the "redundant edge" or "there is a cycle" signal

03

Common mistakes

Missing one of the two optimizations, the code is still correct, just many times slower.

Comparing p[a] == p[b]

You must compare roots: find(a) == find(b). The direct parent says nothing about the group.

Linking p[b] = a instead of the roots

You must link the two roots: p[find(b)] = find(a), otherwise you cut off a branch.

Using DSU on a directed graph

DSU only understands two-way relations. A directed cycle needs a three-state DFS or topological sort.

Pattern 5 — DSU on 2n vertices

Signals: adversarial relations — "these two must be in different groups"

Each element becomes two vertices: x and x+n (the opposing side). If they dislike each other, union(a, b+n) and union(b, a+n). If find(x) == find(x+n), there is a contradiction.
