Union-Find
(DSU)

Trả lời "hai phần tử có cùng nhóm không" gần như tức thì, kể cả khi nhóm đang gộp dần. Đọc 2 phút rồi xuống phần pattern.

01

Mental model

Mỗi nhóm là một cây, và chỉ cần biết gốc. Cùng gốc nghĩa là cùng nhóm — nhưng cây cao bao nhiêu thì mỗi câu hỏi đắt bấy nhiêu, nên hai tối ưu giữ cây thấp là phần thật sự của cấu trúc này.

  • Hai thao tác: find(x) trả về gốc, union(a,b) nối hai gốc lại.
  • Nén đường chữa: mọi nút vừa leo qua được kéo thẳng về gốc. Gộp theo kích thước ngừa: cây nhỏ luôn treo dưới cây lớn.
  • Có đủ cả hai thì mỗi thao tác gần như O(1). Thiếu một cái thì code vẫn ra đúng kết quả — chỉ chậm đi, nên bug này không bao giờ tự lộ ra.
02

Mẫu code cần thuộc

Tám dòng. Phải có cả hai tối ưu: nén đường và gộp theo kích thước.

p = list(range(n)); sz = [1] * n

def find(x):
    while p[x] != x:
        p[x] = p[p[x]]              # nén đường: nhảy cách một bậc
        x = p[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra == rb: return False          # đã cùng nhóm → cạnh này tạo chu trình
    if sz[ra] < sz[rb]: ra, rb = rb, ra  # gộp cây nhỏ vào cây lớn
    p[rb] = ra; sz[ra] += sz[rb]
    return True

union trả về Falsechính là dấu hiệu "cạnh thừa" hoặc "có chu trình"

03

Lỗi hay gặp

Thiếu một trong hai tối ưu thì code vẫn đúng, chỉ chậm gấp nhiều lần.

So sánh p[a] == p[b]

Phải so gốc: find(a) == find(b). Cha trực tiếp không nói lên nhóm.

Nối p[b] = a thay vì nối gốc

Phải nối hai gốc: p[find(b)] = find(a), nếu không sẽ cắt rời một nhánh.

Dùng DSU cho directed graph

DSU chỉ hiểu quan hệ hai chiều. Chu trình có hướng phải dùng DFS ba trạng thái hoặc topo sort.

Pattern 5 — DSU trên 2n đỉnh

Dấu hiệu: quan hệ đối kháng — "hai người này phải khác nhóm"

Mỗi phần tử thành hai đỉnh: x và x+n (phe đối lập). Ghét nhau thì union(a, b+n) và union(b, a+n). Nếu find(x) == find(x+n) thì mâu thuẫn.

10

Hỏi đáp

Tự nghĩ ra ý trả lời trước rồi mới mở — cốt là hiểu ý, không phải thuộc chữ.

Vì sao cần cả hai tối ưu?

Chỉ gộp theo kích thước → cây cao O(log n). Chỉ nén đường → vẫn có ca xấu. Có cả hai mới gần như O(1) mỗi thao tác.

Khi nào DSU thắng DFS?

Khi cạnh tới dần và phải trả lời truy vấn xen kẽ. DFS phải chạy lại từ đầu mỗi lần, DSU thì gộp tại chỗ.

DSU dùng được cho directed graph không?

Không. Nó chỉ hiểu quan hệ hai chiều. Chu trình có hướng phải dùng DFS ba trạng thái hoặc topo sort.

Quan hệ "phải khác nhóm" xử lý thế nào?

Nhân đôi số đỉnh: x và x+n là hai phe. Ghét nhau thì gộp chéo. find(x) == find(x+n) là mâu thuẫn.
