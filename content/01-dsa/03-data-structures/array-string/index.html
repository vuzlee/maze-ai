02

Properties

What each operation really costs.

2.1Read by index

a[i] is O(1) — one jump, whatever the length.

2.2Append at the end

append is O(1) on average — sometimes the block grows and copies.

2.3Insert at the front

insert(0, x) is O(n) — every cell shifts right.

2.4Delete in the middle

pop(i) is O(n − i) — the tail shifts left.

2.5Search by value

x in a is O(n) — no shortcut without order.

2.6Building a string

s += c in a loop copies everything each time — use "".join.
