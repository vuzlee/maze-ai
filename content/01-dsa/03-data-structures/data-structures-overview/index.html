Data structures overview

A lookup page: what each structure costs, and which wording points to which one. The pictures of every structure are on the DSA overview.

01

Operation cost

Find the operation your loop repeats, then pick the row where it is cheap.

  • * averaged over many appends — see Big-O. L = word length.
  • No row is cheap everywhere: the hash map loses order, the BST pays log n for keeping it.
02

Signal to structure

The problem's wording usually names the operation; follow its line to a structure.

03

Learning order

Read top row first: every later structure is built from arrays, pointers or both.
