Data structures — the map

Eight ways to store data, side by side in one table. Open this in the middle of practice to choose fast.

01

Mental model

No storage is good at everything. Store it one way and reads are fast but inserts and deletes are slow, and vice versa.

  • Choosing a structure is choosing which job you want cheap — because the rest will definitely get more expensive.
  • So after reading a problem, the right question is not "which structure" but "what does the innermost loop ask most often" — that column must be green.
02

Choosing a structure

Read the "pick when" column first to narrow it down, then check the cost columns to be sure. The three cost columns carry the operation names common in interviews: access by position, search by value, insert / delete to add and remove.
