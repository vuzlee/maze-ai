Hash map & set

Compute where a key lives — trade memory for time.

01

Mental model

No searching — the slot is computed from the key.

1.1Key to slot

slot = hash(key) % n_slots — a set is the same thing without values.

02

Properties

Fast on average; the cost hides in collisions and resizing.

2.1Get and set

One computation, one look — O(1) on average.

2.2Collisions

Two keys in one slot are chained; the bucket is scanned — O(n) if every key collides.

2.3Resize

Too full → double and rehash every key; rare, so still O(1) on average.
