Tree, BST & traversal

Almost every tree problem is one six-line recursion skeleton. Read for 2 minutes, then go down to the patterns.

01

Mental model

The three traversal orders are not interchangeable: each order exposes a different property of the same tree. Choose by need — children first or node first — not by habit.

  • Postorder is the skeleton for every "a node's result needs its children's results" problem: height, subtree sum, is the tree balanced — section 05.
  • Inorder is the order for every BST problem, and usually you only need to remember the previous element, not the whole sequence — section 07.
  • Level-order BFS is the only one that doesn't recurse naturally: any question mentioning "level", "depth row", "view from the right" belongs to it — section 06.
  • Preorder preserves the tree's shape, so it is used to copy and serialize — but on its own it cannot rebuild the tree, section 09.
02

Recursion skeleton to memorize

Three lines: base case · call both children · combine results. Most problems only change the third line.

def solve(node):
    if not node: return empty_value        # base case
    L = solve(node.left)                  # trust it returns the right thing
    R = solve(node.right)
    return combine(L, R, node.val)        # the only place you need to think

height → 1 + max(L, R)sum → L + R + valbalanced → return (height, is it balanced)

03

Common mistakes

All three finish and return a plausible result — just wrong, or right but far too slow.

Calling a recursive function inside the recursive function

A "is the tree balanced" solution calls height(node.left) right inside the function body — every node re-traverses its whole subtree, giving O(n²).

Follow the skeleton from section 02: return a pair (height, is it balanced) in a single pass.

Forgetting the empty tree

if not node must be the first line. Without it the simplest test fails immediately.

Recursion on a skewed tree

A stick-shaped tree of 10⁵ nodes → stack 10⁵ deep → overflow. Switch to a loop with your own stack.
