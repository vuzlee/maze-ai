Tree, BST & traversal

Nodes with children, walked in the order the question needs.

01

Mental model

A tree is nodes with children; the walk order decides what you see first.

1.1Root, children, leaves

One root on top, at most two children per node, leaves at the bottom.

1.2Preorder

Write the node before its children: the root comes first.

1.3Inorder

Left side, then the node, then the right side: a BST comes out sorted.

1.4Postorder

Write the node after both children: the root comes last.

1.5Level order

A queue visits the tree one level at a time.

02

Properties

In a BST every left value is smaller and every right value bigger, so each operation walks one path: O(h).

2.1Search

Compare, then drop a whole side.

2.2Insert

Walk down like a search; the new node goes where the walk falls off.

2.3Delete

Two children: copy in the next bigger value, then delete that leaf.

2.4Height decides the cost

Balanced: O(log n). A chain: O(n).
