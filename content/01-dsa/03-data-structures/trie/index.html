Trie — the prefix tree

A specialized structure: it beats a hash map at only one job, but at that job it has no rival.

01

Mental model

Words with a common prefix share a path. Looking up a word costs O(L) for word length L, independent of how many words are stored.

  • A prefix lookup is just walking down character by character and stopping — a hash map cannot do this.
  • Cost O(L) where L is the key length: a store of a million words is as fast to search as one of ten.
02

Code template to memorize

A nested dict is enough. Just add one key marking the end of a word.

END = "#"

def insert(root, word):
    node = root
    for ch in word:
        node = node.setdefault(ch, {})   # create the branch if missing
    node[END] = True                   # mark the end of a word

def walk(root, s):                       # follow string s, return the last node
    node = root
    for ch in s:
        if ch not in node: return None
        node = node[ch]
    return node

search      = lambda r, w: (walk(r, w) or {}).get(END, False)
starts_with = lambda r, p: walk(r, p) is not None

the only difference between search and startsWithis whether you check for the END key

03

Trie vs hash map

For exact lookups the hash map wins. For prefix lookups only the trie can do it.

TaskHash mapTrie
"is this word in the store"O(1)* — fasterO(L)
"does any word start with ca"can't do it — must scan everythingO(L)
"list every word starting with ca"O(words)O(results)
Memorymore compactmore costly — one dict per node
Lexicographic ordernonea DFS gives it immediately

* hashing a string also costs O(L)so the real gap is much smaller than the notation suggests

04

Common mistakes

The first trap makes search("ca") return true when the store only has "car".

Forgetting to mark the end of a word

Without the END key, every prefix is treated as a complete word.

Assuming a trie saves memory

It only saves memory when prefixes overlap a lot. With random words it costs far more than a set.

Large alphabets

A 26-slot array per node breaks immediately with Unicode. Use a dict so you only pay for characters that actually appear.
