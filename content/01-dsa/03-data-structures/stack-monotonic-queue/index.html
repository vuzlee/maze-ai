Stack &
monotonic stack

One code template that turns O(n²) into O(n). Read for 2 minutes, then go down to the patterns to practice.

01

Mental model

A stack is a holding place for things not yet resolved. When a new element resolves someone, pop that one out — and that is why a while loop inside a for loop still costs only O(n).

  • Each index enters the stack exactly once and leaves exactly once → 2n operations total → O(n). This way of counting is called amortized analysis — averaging over the whole series of operations, not costing the worst step on its own.
  • Use it when the question looks like "the nearest element to the left/right that is larger / smaller" — the stack then always holds a monotonic sequence, hence the name monotonic stack.
  • Whatever is still stuck in the stack when the array ends has no answer (the 6 and the 3 in the figure) — handle it separately, don't forget it.
02

Code template to memorize

Change one comparison sign and you get four variants: larger / smaller, left / right.

# nearest LARGER element to the RIGHT
st, res = [], [-1] * n            # st holds INDICES, not values
for i in range(n):
    while st and a[st[-1]] < a[i]:   # a[i] resolves the stack top
        res[st.pop()] = a[i]
    st.append(i)
Change direction

right → iterate forward

left → iterate backward range(n-1, -1, -1)

Change comparison

larger → a[st[-1]] < a[i]

smaller → a[st[-1]] > a[i]

03

Common mistakes

The first two traps fail silently — the code still runs and still produces output.

Pushing values instead of indices

Only by keeping indices can you compute distances and write into the right result cell.

The while condition reads a[i] after popping

If the while body does st.pop() and then reads a[st[-1]], the next iteration compares against a different element — or raises IndexError when the stack is empty. Read first, pop after.

Mixing up < and <=

With equal elements, the = decides whether you take the first or the last of the equal group.

Pattern 4 — deque for windows

Signals: "max / min of every window of length k"

A monotonic stack that can drop from both ends becomes a monotonic deque.

while dq and a[dq[-1]] < a[i]: dq.pop()        # drop at the back: smaller is useless
dq.append(i)
if dq[0] <= i - k: dq.popleft()              # drop at the front: left the window
# dq[0] is always the index of the window max
