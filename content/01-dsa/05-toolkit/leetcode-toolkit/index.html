Tools

1.1bisect

1.2Counter

Count every value in one pass; a missing key reads as 0.

1.3defaultdict

A missing key starts with a default, so grouping needs no key check.

1.4deque

Take from the front without shifting the rest.

1.5heapq

The smallest item is always at index 0; push and pop cost O(log n).

1.6Comprehension

Filter and transform a list in one line.
